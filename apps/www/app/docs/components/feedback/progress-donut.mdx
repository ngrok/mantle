# Progress Donut

Displays an indicator showing the completion progress of a task as a circular progress bar. Give `ProgressDonut.Root` an `aria-label`, or a screen reader announces a bare "progress bar".

<Example name="components/feedback/progress-donut/overview" title="Progress Donut example">

```tsx
import { ProgressDonut } from "@ngrok/mantle/progress";

<ProgressDonut.Root
	aria-label="Task progress"
	value={60}
	className="size-10"
	strokeWidth="0.375rem"
>
	<ProgressDonut.Indicator />
</ProgressDonut.Root>;
```

</Example>

## When to use

- Show how much of a task or a quota is complete, as a small circle.
- Prefer [`ProgressBar`](/components/feedback/progress-bar) when the indicator is a horizontal bar.

## Indicator color

The indicator color is inherited via `currentColor`. Override the default (`accent-600`) by setting the `ProgressDonut.Indicator`'s text color.

<Example name="components/feedback/progress-donut/indicator-color" title="Progress Donut indicator color example">

```tsx
import { ProgressDonut } from "@ngrok/mantle/progress";

<ProgressDonut.Root
	aria-label="Task progress"
	value={60}
	className="size-10"
	strokeWidth="0.375rem"
>
	<ProgressDonut.Indicator className="text-fuchsia-600" />
</ProgressDonut.Root>;
```

</Example>

## Accessibility

`ProgressDonut.Root` renders `role="progressbar"` with `aria-valuemin`, `aria-valuemax`, and `aria-valuenow`, and omits `aria-valuenow` while indeterminate. The role needs a name: pass `aria-label`, or `aria-labelledby` that points at a visible label, or a screen reader announces a bare "progress bar".

## Indeterminate value

Set the `value` prop to `"indeterminate"` to show the donut in an indeterminate state.

Control the rotation speed with the `indeterminateRotationSpeed` prop.

<Example name="components/feedback/progress-donut/indeterminate-value" title="Progress Donut indeterminate value example">

```tsx
import { ProgressDonut } from "@ngrok/mantle/progress";

<ProgressDonut.Root aria-label="Task progress" className="size-10" value="indeterminate" strokeWidth="0.375rem">
	<ProgressDonut.Indicator />
</ProgressDonut.Root>

<ProgressDonut.Root
	aria-label="Task progress"
	className="size-10"
	value="indeterminate"
	indeterminateRotationSpeed="animation-duration-[2s]"
	strokeWidth="0.375rem"
>
	<ProgressDonut.Indicator />
</ProgressDonut.Root>
```

</Example>

## Dynamic colors

`ProgressDonut.Indicator` inherits its color from the parent text color through `currentColor`. Set the parent's text color to change the indicator based on the current progress value.

<Example name="components/feedback/progress-donut/dynamic-colors" title="Progress Donut dynamic colors example">

```tsx
import { ProgressDonut } from "@ngrok/mantle/progress";

const Example = () => {
	const [value, setValue] = useState(0);

	function computeColor() {
		if (value <= 20) {
			return "text-accent-600";
		}
		if (value <= 40) {
			return "text-success-600";
		}
		if (value <= 60) {
			return "text-warning-600";
		}
		if (value <= 80) {
			return "text-fuchsia-600";
		}
		return "text-danger-600";
	}

	return (
		<form className="space-y-4">
			<ProgressDonut.Root
				aria-label="Task progress"
				value={value}
				className="size-10"
				strokeWidth="0.375rem"
			>
				<ProgressDonut.Indicator className={computeColor()} />
			</ProgressDonut.Root>
			<label className="block space-y-1">
				<p>Value:</p>
				<input
					type="range"
					min={0}
					max={100}
					value={value}
					onChange={(e) => setValue(Number(e.target.value))}
				/>{" "}
				({value}%)
			</label>
		</form>
	);
};
```

</Example>

## Composition

Compose the parts of a `ProgressDonut` together to build your own:

```text showLineNumbers=false
ProgressDonut.Root
└── ProgressDonut.Indicator
```

## API Reference

### ProgressDonut.Root

A simple circular progress bar which shows the completion progress of a task.

The indicator color is inherited via `currentColor`. Override the default (`accent-600`) by setting the `ProgressDonut.Indicator`'s text color.

The `ProgressDonut` accepts the following props in addition to the [standard HTML svg attributes](https://developer.mozilla.org/en-US/docs/Web/SVG/Element/svg#attributes).

| Prop                         | Type                                 | Default                      | Description                                                                                                                                                                                         |
| ---------------------------- | ------------------------------------ | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `indeterminateRotationSpeed` | `` `animation-duration-${string}` `` | `"animation-duration-[15s]"` | Controls the rotation speed of the indeterminate spinner state, as a Tailwind `animation-duration-*` class.                                                                                         |
| `max`                        | `number`                             | `100`                        | The maximum value of the progress bar. Must have a value greater than 0.                                                                                                                            |
| `strokeWidth`                | `number` \| `` `${number}rem` ``     | `"0.25rem"`                  | The width of the progress bar stroke, clamped between 1px and 12px.                                                                                                                                 |
| `value`                      | `number` \| `"indeterminate"`        | `0`                          | The current value of the progress bar. Must be between 0 and `max`; a value outside that range renders as indeterminate. If set to `"indeterminate"`, the progress bar is considered indeterminate. |

| Data Attribute       | Value                       | Description       |
| -------------------- | --------------------------- | ----------------- |
| `data-slot`          | `"progress-donut"`          | The root `<svg>`. |
| `data-indeterminate` | present while indeterminate | Presence-only.    |

### ProgressDonut.Indicator

The indicator for the circular progress bar.

All props from [svg g](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/g).
