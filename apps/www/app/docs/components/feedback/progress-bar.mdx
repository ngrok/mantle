# Progress Bar

Displays an indicator showing the completion progress of a task as a linear progress bar with customizable colors. Give `ProgressBar.Root` an `aria-label`, or a screen reader announces a bare "progress bar".

<Example name="components/feedback/progress-bar/overview" title="Progress Bar example">

```tsx
import { ProgressBar } from "@ngrok/mantle/progress";

<ProgressBar.Root aria-label="Task progress" value={60}>
	<ProgressBar.Indicator />
</ProgressBar.Root>;
```

</Example>

## When to use

- Show how much of a task or a quota is complete, as a horizontal bar.
- Prefer [`ProgressDonut`](/components/feedback/progress-donut) when the indicator must be a small circle.
- Prefer [`Skeleton`](/components/feedback/skeleton) when the content still loads, and its progress is unknown.

## Indicator color

The indicator is `bg-accent-600` by default. Set another background color on `ProgressBar.Indicator` with `className`.

<Example name="components/feedback/progress-bar/indicator-color" title="Progress Bar indicator color example">

```tsx
import { ProgressBar } from "@ngrok/mantle/progress";

<ProgressBar.Root aria-label="Task progress" value={60}>
	<ProgressBar.Indicator className="bg-warning-600" />
</ProgressBar.Root>
<ProgressBar.Root aria-label="Task progress" value={30}>
	<ProgressBar.Indicator className="bg-accent-600" />
</ProgressBar.Root>
<ProgressBar.Root aria-label="Task progress" value={85}>
	<ProgressBar.Indicator className="bg-emerald-600" />
</ProgressBar.Root>
```

</Example>

## With a label

Put a short status label beside a narrow bar to show the state of each item in a list.

<Example name="components/feedback/progress-bar/with-a-label" title="Progress Bar with a label example">

```tsx
import { ProgressBar } from "@ngrok/mantle/progress";

<div className="flex flex-col gap-3">
	<div className="flex items-center gap-3 text-sm">
		<ProgressBar.Root aria-label="Complete" value={100} className="w-24">
			<ProgressBar.Indicator className="bg-success-600" />
		</ProgressBar.Root>
		Complete
	</div>
	<div className="flex items-center gap-3 text-sm">
		<ProgressBar.Root aria-label="In progress" value={45} className="w-24">
			<ProgressBar.Indicator className="bg-warning-600" />
		</ProgressBar.Root>
		In Progress
	</div>
	<div className="flex items-center gap-3 text-sm">
		<ProgressBar.Root aria-label="Starting" value={10} className="w-24">
			<ProgressBar.Indicator className="bg-danger-600" />
		</ProgressBar.Root>
		Starting
	</div>
</div>;
```

</Example>

## Accessibility

`ProgressBar.Root` renders `role="progressbar"` with `aria-valuemin`, `aria-valuemax`, and `aria-valuenow`, and omits `aria-valuenow` while indeterminate. The role needs a name: pass `aria-label`, or `aria-labelledby` that points at a visible label, or a screen reader announces a bare "progress bar".

## Custom maximum value

Set a custom maximum value with the `max` prop. The progress bar renders the value as a percentage of that maximum.

<Example name="components/feedback/progress-bar/custom-maximum-value" title="Progress Bar custom maximum value example">

```tsx
import { ProgressBar } from "@ngrok/mantle/progress";

<ProgressBar.Root aria-label="Task progress" value={150} max={200}>
	<ProgressBar.Indicator className="bg-purple-600" />
</ProgressBar.Root>;
```

</Example>

## Indeterminate value

Set the `value` prop to `"indeterminate"` to show the progress bar in an indeterminate state. Currently, this displays as a progress bar at 0% but keeps accessibility attributes for screen readers.

<Example name="components/feedback/progress-bar/indeterminate-value" title="Progress Bar indeterminate value example">

```tsx
import { ProgressBar } from "@ngrok/mantle/progress";

<ProgressBar.Root aria-label="Task progress" value="indeterminate">
	<ProgressBar.Indicator className="bg-accent-600" />
</ProgressBar.Root>;
```

</Example>

## Dynamic colors

Set the color of the `ProgressBar.Indicator` with the `className` prop to change colors based on the current progress value or application state.

<Example name="components/feedback/progress-bar/dynamic-colors" title="Progress Bar dynamic colors example">

```tsx
import { ProgressBar } from "@ngrok/mantle/progress";

const Example = () => {
	const [value, setValue] = useState(0);

	function computeIndicatorColor() {
		if (value <= 20) {
			return "bg-danger-600";
		}
		if (value <= 40) {
			return "bg-warning-600";
		}
		if (value <= 60) {
			return "bg-accent-600";
		}
		if (value <= 80) {
			return "bg-success-600";
		}
		return "bg-fuchsia-600";
	}

	return (
		<form className="space-y-4">
			<ProgressBar.Root aria-label="Task progress" value={value}>
				<ProgressBar.Indicator className={computeIndicatorColor()} />
			</ProgressBar.Root>
			<label className="block space-y-1">
				<p>Value:</p>
				<input
					type="range"
					min={0}
					max={100}
					value={value}
					onChange={(e) => setValue(Number(e.target.value))}
				/>{" "}
				({value}%)
			</label>
		</form>
	);
};
```

</Example>

## Composition

The progress bar consists of an indicator (filled portion) that shows the current progress value against a background container. Compose the parts of a `ProgressBar` together to build your own:

```text showLineNumbers=false
ProgressBar.Root
└── ProgressBar.Indicator
```

## API Reference

### ProgressBar.Root

A linear progress bar that displays completion progress with customizable colors.

The `ProgressBar.Root` accepts the following props in addition to the [standard HTML div attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes).

| Prop    | Type                          | Default | Description                                                                                                                                                                                         |
| ------- | ----------------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `max`   | `number`                      | `100`   | The maximum value of the progress bar. Must have a value greater than 0.                                                                                                                            |
| `value` | `number` \| `"indeterminate"` | `0`     | The current value of the progress bar. Must be between 0 and `max`; a value outside that range renders as indeterminate. If set to `"indeterminate"`, the progress bar is considered indeterminate. |

| Data Attribute | Value                                            | Description                          |
| -------------- | ------------------------------------------------ | ------------------------------------ |
| `data-slot`    | `"progress-bar"`                                 | The root element.                    |
| `data-state`   | `"complete"` \| `"indeterminate"` \| `"loading"` | Set by Radix from `value` and `max`. |
| `data-value`   | the current value                                | Absent while indeterminate.          |
| `data-max`     | the maximum                                      |                                      |

### ProgressBar.Indicator

The indicator portion of the progress bar that shows the completed progress. It positions itself from the current value relative to `max`.

All props from [HTML div element](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div).
