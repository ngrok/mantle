<PageHeader id="list">List</PageHeader>

A scrollable, optionally-virtualized list of clickable items. Compose `List.Item` rows inside a `List.Root`, and give each row an `onClick`.

<Example example="components/data-display/list/overview" title="List example" />

```tsx
import { List } from "@ngrok/mantle/list";

const accounts = [
	{ id: "personal", name: "Cody Price", plan: "All Subscription" },
	{ id: "corp", name: "corp@ngrok.com", plan: "Enterprise Subscription" },
	{ id: "dogfood", name: "dogfood@ngrok.com", plan: "Free" },
];

<List.Root aria-label="Switch account" className="max-h-80">
	{accounts.map((account) => (
		<List.Item key={account.id} onClick={() => {}}>
			<List.ItemTitle>{account.name}</List.ItemTitle>
			<List.ItemDescription>{account.plan}</List.ItemDescription>
		</List.Item>
	))}
</List.Root>;
```

## When to use

- Show a scrollable list of items that each run an action or navigate, such as an account switcher or an SSO provider picker.
- Show a long list: swap `Root` for [`VirtualRoot`](#virtualization) to window the rows. `Root` renders every row.
- Prefer [`SelectableList`](/components/data-display/selectable-list) when the user selects rows with checkboxes. `List` is its action and navigation counterpart.
- Prefer [`DropdownMenu`](/components/overlays/dropdown-menu) when the actions open in a menu from a button.

## Current row

Set `current` on one `List.Item` to highlight it, such as the active account in an account switcher.

<Example example="components/data-display/list/current-row" title="List current row example" />

```tsx
import { List } from "@ngrok/mantle/list";
import { useState } from "react";

function Example() {
	const [activeId, setActiveId] = useState("account-2");

	return (
		<List.Root aria-label="Your accounts" className="max-h-80">
			{accounts.map((account) => (
				<List.Item
					key={account.id}
					current={account.id === activeId}
					onClick={() => setActiveId(account.id)}
				>
					<List.ItemTitle>{account.name}</List.ItemTitle>
					<List.ItemDescription>
						{account.plan} · {account.memberCount} members
					</List.ItemDescription>
				</List.Item>
			))}
		</List.Root>
	);
}
```

## Composition

```text showLineNumbers=false
List.Root   (or .VirtualRoot)
└── List.Item
    ├── List.ItemTitle
    └── List.ItemDescription
```

- **`Root`** renders the rounded, scrollable `bg-popover` container and its `Item` children (all of them, non-virtualized). Reads each item's `current` / `disabled` to style its row. **Bound its height** (`max-h-*`, `h-*`, or `min-h-0 flex-1` in a flex parent) so long lists scroll.
- **`VirtualRoot`** is the drop-in windowed variant: same `Item` children, only the visible slice mounted. See [Virtualization](#virtualization).
- **`Item`** is a clickable row: a `<button>` by default (`onClick`), or your own element via `asChild`. `current` gives the tinted pill.
- **`ItemTitle` / `ItemDescription`** are optional styled spans for the emphasized title and de-emphasized sub-line.

## Virtualization

`List.Root` renders every row: simplest, and right for the short lists most action/navigation menus are. For a long list (hundreds+ of rows), swap in `List.VirtualRoot`: it windows the same `Item` children via [`@tanstack/react-virtual`](https://tanstack.com/virtual), mounting only what's visible. The call site is otherwise identical: same children, same props. (`@tanstack/react-virtual` ships with every list entrypoint; it is small, a few kB gzipped, and does no windowing work until a `VirtualRoot` renders.)

On the server, `VirtualRoot` renders the first slice of rows, sized by `estimateItemHeight` and `overscan`. The rest mount after hydration measures the viewport. `Root` renders every row in the server HTML. If the whole list must be in that HTML (for find-in-page, or for a reader without JavaScript), pick `Root`.

<Example
	example="components/data-display/list/virtualization"
	title="List virtualization example"
/>

```tsx
import { List } from "@ngrok/mantle/list";
import { useState } from "react";

// `VirtualRoot` is a drop-in for `Root` — same `Item` children, same props.
function Example() {
	const [activeId, setActiveId] = useState("account-2");

	return (
		<List.VirtualRoot aria-label="Your accounts" className="max-h-80">
			{accounts.map((account) => (
				<List.Item
					key={account.id}
					current={account.id === activeId}
					onClick={() => setActiveId(account.id)}
				>
					<List.ItemTitle>{account.name}</List.ItemTitle>
					<List.ItemDescription>
						{account.plan} · {account.memberCount} members
					</List.ItemDescription>
				</List.Item>
			))}
		</List.VirtualRoot>
	);
}
```

> **Windowing trade-off.** Off-screen rows aren't in the DOM, so Tab and browser find-in-page only reach mounted rows (arrow keys still span the full list; they mount the target row before focusing it). That is the right trade for a large enough list. Prefer `Root` until a list is actually long.

## Polymorphism

Render rows as links by passing `asChild` and an `<a>`: the row chrome (hover pill, keyboard-focus tint) applies to your element, so clicking navigates. Rows compose freely: each one here is a [`MediaObject`](/components/structure/media-object) with the provider icon on the left and the name over a de-emphasized owner on the right (an SSO identity-provider picker, as a list rather than a stack of cards).

<Example example="components/data-display/list/polymorphism" title="List polymorphism example" />

```tsx
import { cx } from "@ngrok/mantle/cx";
import { MediaObject } from "@ngrok/mantle/media-object";
import { List } from "@ngrok/mantle/list";

<List.Root aria-label="Identity providers" className="max-h-72">
	{providers.map((provider) => (
		<List.Item key={provider.id} asChild className="py-2.5">
			<a href={`#${provider.id}`}>
				<MediaObject.Root className="items-center gap-3">
					<MediaObject.Media>
						<provider.Icon weight="duotone" className={cx("size-8", provider.tint)} />
					</MediaObject.Media>
					<MediaObject.Content className="flex flex-col gap-0.5">
						<List.ItemTitle>{provider.name}</List.ItemTitle>
						<List.ItemDescription>{provider.owner}</List.ItemDescription>
					</MediaObject.Content>
				</MediaObject.Root>
			</a>
		</List.Item>
	))}
</List.Root>;
```

## Appearance

`List` shares the look of [`SelectableList`](/components/data-display/selectable-list), which is styled like the [`MultiSelect`](/components/forms/multi-select) popover. Rows highlight on hover and on selection as an inset, rounded pill inside a bordered `bg-popover` container.

## Accessibility

The list is a `role="list"` of `role="listitem"` rows (the tag is a `<div>`; per WAI-ARIA the role, not the tag, carries the semantics); each `Item` is a focusable `<button>` (or your `asChild` element) inside its row. It is a **non-selecting** list, not a selection widget; that's [`SelectableList`](/components/data-display/selectable-list)'s job. Set an `aria-label` (or `aria-labelledby`) on the `Root` so the list has an accessible name. The `current` row is announced via `aria-current`, not just tinted. Disabled rows are dimmed: a `<button>` row sets the native `disabled`, while an `asChild` row is conveyed with `aria-disabled`, removed from the tab order, and swallows clicks. For a genuinely disabled link, prefer omitting or removing the `href`.

Keyboard: rows keep their native tab order, and `Arrow`↑/`Arrow`↓ / `Home` / `End` also move focus between rows, skipping disabled ones (no wrap; arrowing past the last row holds). The focused row lights up with the same tint as hover instead of drawing a focus ring on the item, matching the [`SelectableList`](/components/data-display/selectable-list) active row. Arrow navigation works under `VirtualRoot` too (a jump scrolls the target row into view and mounts it before moving focus), though off-screen rows still aren't reachable by Tab alone (see [Virtualization](#virtualization)).

## API Reference

### List.Root

The non-virtualized container. Accepts all `<div>` props, plus:

| Prop       | Type        | Default | Description                          |
| ---------- | ----------- | ------- | ------------------------------------ |
| `children` | `ReactNode` |         | `List.Item` rows (all are rendered). |

Bound the height (e.g. `className="max-h-80"`) so long lists scroll.

### List.VirtualRoot

The windowed container — same surface as `Root` (compose the same `Item` children), plus the virtualizer knobs:

| Prop                  | Type        | Default | Description                                                                                                                             |
| --------------------- | ----------- | ------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `children`            | `ReactNode` |         | `List.Item` rows (only the visible window is mounted).                                                                                  |
| `estimateItemHeight?` | `number`    | `44`    | Estimated item height (px) used to seed the virtualizer before measure. With `overscan`, it also sizes the server-rendered first slice. |
| `overscan?`           | `number`    | `8`     | Rows rendered beyond the visible window on each side.                                                                                   |

### List.Item

A clickable row. Accepts all `<button>` props (minus `type`), plus:

| Prop        | Type      | Default | Description                                                                                                                                                                               |
| ----------- | --------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `current?`  | `boolean` | `false` | Marks the row as the current one (tinted pill) and sets `aria-current`, so the state is announced, not just shown. Omit for a plain action/navigation list.                               |
| `disabled?` | `boolean` | `false` | Disables the row (dimmed). `disabled` on the button; with `asChild`, `aria-disabled` + removal from the tab order, and clicks are swallowed — prefer omitting `href` for a disabled link. |
| `asChild?`  | `boolean` | `false` | Render the row as the provided child element (e.g. an `<a>`) instead of a `<button>`.                                                                                                     |

### List.ItemTitle / List.ItemDescription

Styled `<span>`s for the title and de-emphasized sub-line inside an `Item`. Both accept all `<span>` props.
