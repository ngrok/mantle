# Typography

Headings and paragraphs in the site's type scale, plus a container that styles HTML from a CMS or MDX. Each part reads a type-role token, so a site sets its own scale in CSS and the markup stays the same.

<Example name="components/data-display/typography/overview" title="Typography example">

```tsx
import { Typography } from "@ngrok/mantle/typography";

<Typography.Root>
	<Typography.H1>Endpoints</Typography.H1>
	<Typography.P className="text-lead">Each endpoint gets a public URL.</Typography.P>
	<Typography.H2>Traffic policy</Typography.H2>
	<Typography.P>Attach a traffic policy to filter, route, or rewrite requests.</Typography.P>
</Typography.Root>;
```

</Example>

## When to use

- Show a page title, a section heading, or a paragraph of copy in the site's type scale.
- Style HTML that you can't map to components, such as CMS or MDX output, with `Typography.Root`.
- Prefer `Card.Title` from [`Card`](/components/structure/card) for the title of a card.
- Prefer `Dialog.Title` from [`Dialog`](/components/overlays/dialog) for the title of a dialog.
- Prefer [`Code`](/components/data-display/code) for a fragment of code.

## Headings

`Typography.H1` through `Typography.H6` each render the heading element of their name in its type role. `Typography.H6` is uppercase.

<Example name="components/data-display/typography/headings" title="Typography headings example">

```tsx
import { Typography } from "@ngrok/mantle/typography";

<div className="flex flex-col items-start gap-4">
	<Typography.H1>Heading 1</Typography.H1>
	<Typography.H2>Heading 2</Typography.H2>
	<Typography.H3>Heading 3</Typography.H3>
	<Typography.H4>Heading 4</Typography.H4>
	<Typography.H5>Heading 5</Typography.H5>
	<Typography.H6>Heading 6</Typography.H6>
</div>;
```

</Example>

## Another level's look

The part sets the level in the document outline. To give it the look of another level, pass that level's type role in `className`. Your class replaces the part's own role.

<Example name="components/data-display/typography/another-levels-look" title="Typography heading with another level's look example">

```tsx
import { Typography } from "@ngrok/mantle/typography";

<Typography.H2 className="text-heading-4">Danger zone</Typography.H2>;
```

</Example>

## Lead paragraph

Pass `text-lead` to `Typography.P` for the larger paragraph under a page title.

<Example name="components/data-display/typography/lead-paragraph" title="Typography lead paragraph example">

```tsx
import { Typography } from "@ngrok/mantle/typography";

<div className="flex flex-col items-start gap-2">
	<Typography.P className="text-lead">Put your app online in one command.</Typography.P>
	<Typography.P>
		ngrok gives each agent a public URL and forwards its traffic to your app.
	</Typography.P>
</div>;
```

</Example>

## HTML from a CMS

`Typography.Root` styles the headings, paragraphs, and lists directly inside it. Use it for HTML that you can't map to components. It styles direct children only, so a component inside it keeps its own styles, and a class on a child wins over the container's styles.

<Example name="components/data-display/typography/html-from-a-cms" title="Typography HTML from a CMS example">

```tsx
import { Typography } from "@ngrok/mantle/typography";

const html =
	"<h2>Install the agent</h2><p>Download the agent for your platform.</p><ul><li>macOS</li><li>Linux</li><li>Windows</li></ul>";

<Typography.Root asChild>
	<article dangerouslySetInnerHTML={{ __html: html }} />
</Typography.Root>;
```

</Example>

## A scale for one section

The type roles are CSS variables, so any element can set a different scale for the parts inside it. Set every sub-key of a role you change: a sub-key you leave out keeps the site's value. To set the scale for a whole site, see [Typography](/base/typography#set-a-sites-scale).

<Example name="components/data-display/typography/a-scale-for-one-section" title="Typography scale for one section example">

```tsx
import { Typography } from "@ngrok/mantle/typography";

<section className="[--text-heading-1--font-weight:700] [--text-heading-1--line-height:1] [--text-heading-1:4rem]">
	<Typography.H1>Put your app online</Typography.H1>
</section>;
```

</Example>

## Composition

Each part works on its own. `Typography.Root` is optional: use it when HTML inside it needs the type scale.

```text showLineNumbers=false
Typography.Root
├── Typography.H1
├── Typography.H2
├── Typography.H3
├── Typography.H4
├── Typography.H5
├── Typography.H6
└── Typography.P
```

## Polymorphism

Every `Typography` part accepts an `asChild` prop. When `true`, the part renders its single child instead of its default element, and forwards its class names, `data-*` attributes, and ref onto that child. Use it on `Typography.Root` to render an `article` or a `section`. Keep a heading part on a heading element, so the document outline stays correct.

<Example name="components/data-display/typography/polymorphism" title="Typography polymorphism example">

```tsx
import { Typography } from "@ngrok/mantle/typography";

<Typography.Root asChild>
	<article>
		<Typography.H2>Release notes</Typography.H2>
		<Typography.P>This release adds traffic policy support to agent endpoints.</Typography.P>
	</article>
</Typography.Root>;
```

</Example>

## API Reference

### Typography.Root

A container that styles the headings, paragraphs, and lists directly inside it with the type-role tokens. It renders a `div` with the `type-prose` utility.

All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes), plus:

| Prop       | Type      | Default | Description                                                                                                                  |
| ---------- | --------- | ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose the `Typography.Root` styling onto alternative element types or your own React components. |
