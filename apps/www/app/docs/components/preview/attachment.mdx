A file attached to a chat message, as a chip with its preview, name, size, and a remove button. Use it in [Prompt Input](/components/preview/prompt-input) for a draft, and under a sent message.

<Example name="components/preview/attachment/overview" title="Attachment example">

```tsx
import { Attachment } from "@ngrok/mantle/attachment";
import { useState } from "react";

const draftFiles = [
	{ id: "policy", name: "traffic-policy.yaml", size: 2_340 },
	{ id: "logs", name: "endpoint-logs-2026-11-23.json", size: 1_843_200 },
];

function DraftAttachments() {
	const [files, setFiles] = useState(draftFiles);

	return (
		<>
			<Attachment.List aria-label="Attachments">
				{files.map((file) => (
					<Attachment.Root key={file.id}>
						<Attachment.Preview />
						<Attachment.Name title={file.name}>{file.name}</Attachment.Name>
						<Attachment.Size bytes={file.size} />
						<Attachment.Remove
							label={`Remove ${file.name}`}
							onClick={() => setFiles((current) => current.filter((item) => item.id !== file.id))}
						/>
					</Attachment.Root>
				))}
			</Attachment.List>
		</>
	);
}
```

</Example>

## When to use

- Show the files attached to a chat message, with a remove button while the message is a draft.
- Leave out `Attachment.Remove` where a file cannot be removed, such as in a sent message.
- Use [Prompt Input](/components/preview/prompt-input) to take the files.

## A file the app still reads

Set `busy` on `Attachment.Root` while your app reads a file, and show a [Skeleton](/components/feedback/skeleton) in place of `Attachment.Preview`. The chip sets `aria-busy`.

<Example name="components/preview/attachment/busy" title="Attachment busy example">

```tsx
import { Attachment } from "@ngrok/mantle/attachment";
import { Skeleton } from "@ngrok/mantle/skeleton";

function ReadingAttachment() {
	return (
		<>
			<Attachment.List aria-label="Attachments">
				<Attachment.Root busy>
					<Skeleton className="size-8 rounded" />
					<Attachment.Name>screenshot.png</Attachment.Name>
					<Attachment.Size bytes={482_000} />
				</Attachment.Root>
			</Attachment.List>
		</>
	);
}
```

</Example>

## Translation

`Attachment.Name` sets `translate="no"`, because a file name is an identifier.

## Composition

```text showLineNumbers=false
Attachment.List
└── Attachment.Root
    ├── Attachment.Preview
    ├── Attachment.Name
    ├── Attachment.Size
    └── Attachment.Remove
```

## Polymorphism

`Attachment.List`, `Attachment.Root`, and `Attachment.Name` take `asChild`. `Attachment.Preview` picks between an image and an icon, `Attachment.Size` renders its own text, and `Attachment.Remove` owns its icon, so those three do not.

## API Reference

### Attachment.List

The list of attached files, as chips that wrap. Name it, such as `aria-label="Attachments"`.

All props from [ul](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/ul#attributes), plus:

| Prop       | Type      | Default | Description                                       |
| ---------- | --------- | ------- | ------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Render as a different element by passing a child. |

### Attachment.Root

One attached file. The chip lays out its parts by their `data-slot`: the preview on the left, the name over the size, and the remove button on the right.

All props from [li](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/li#attributes), plus:

| Prop       | Type      | Default | Description                                                    |
| ---------- | --------- | ------- | -------------------------------------------------------------- |
| `busy?`    | `boolean` | `false` | True while your app reads the file. The chip sets `aria-busy`. |
| `asChild?` | `boolean` | `false` | Render as a different element by passing a child.              |

### Attachment.Preview

A 32-pixel thumbnail of an image file, or a file icon when `src` is not set. It is decorative.

All props from [img](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/img#attributes) except `alt`, `width`, and `height`.

### Attachment.Name

The file's name. It truncates when the chip is narrow, and never translates. Set `title` to show the whole name on hover.

All props from [span](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/span) except `translate`, plus:

| Prop       | Type      | Default | Description                                       |
| ---------- | --------- | ------- | ------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Render as a different element by passing a child. |

### Attachment.Size

The file's size, such as "1.5 KB".

All props from [span](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/span) except `children`, plus:

| Prop    | Type     | Default | Description                         |
| ------- | -------- | ------- | ----------------------------------- |
| `bytes` | `number` |         | The file's size in bytes. Required. |

### Attachment.Remove

The button that removes the file. Name the file in `label`, such as "Remove report.pdf".

All props from [Icon Button](/components/actions/icon-button) except `appearance`, `asChild`, `icon`, `intent`, and `type`. `label` is required.
