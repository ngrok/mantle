## When to use

- Show side-panel content that slides in from the left or right edge, such as a filter panel, a detail or inspector view, a navigation drawer, or a mobile menu.
- Let the user complete a task without losing the context of the view beneath the sheet.
- Prefer [`Dialog`](/components/overlays/dialog) for a centered modal.
- Prefer [`AlertDialog`](/components/overlays/alert-dialog) for a destructive or irreversible confirmation.
- Prefer [`Sidebar`](/components/navigation/sidebar) for the persistent navigation of the app.

## Layering and z-index

`Sheet.Content` renders its floating layer at Tailwind `z-60`, Mantle's overlay tier, above every float (`z-50`). Floats composed inside the content portal into the positioner (`data-slot="sheet-positioner"`) and paint above the content. When multiple overlays are open, the most recently mounted overlay renders on top.

`Sheet`, `Dialog`, and `AlertDialog` each render their own backdrop, so stacking modal layers compounds the dim and blur effect on the layers underneath.

## UI above an open sheet

UI that must take clicks above an open sheet, such as a consent banner, carries the `overlay-prompt` class. A click inside it does not count as an outside click. Add `pointer-events-auto` too, because the open sheet sets `pointer-events: none` on `<body>`. mantle's `Toaster` does both.

```tsx
<div className="overlay-prompt pointer-events-auto fixed inset-x-0 bottom-0 z-max">
	<ConsentBanner />
</div>
```

The class reaches pointer input only. The open sheet traps keyboard focus and hides outside content from assistive technology with `aria-hidden`, so a keyboard or screen reader user cannot reach the banner. Put a control that every user must reach inside the sheet content.

## Third-party popups

A script can show its own popup in a frame on `<body>`, above the sheet. A payment script does this for a 3-D Secure challenge and for a wallet sign-in. While that frame is on top at the center of the viewport, the sheet yields to the popup:

- Focus that the script moves into the popup stays there. The focus trap does not take it back.
- Escape does not close the sheet. It moves focus into the popup, and the popup then takes the keyboard.
- A click in the popup is not an outside click.

The sheet finds the popup with a hit test at the center of the viewport. The popup counts when:

- the element on top there is a frame, and the frame takes pointer input
- the frame is in a child of `<body>` that has a `position` and a `z-index` at or above the `z-60` of the sheet

An open sheet sets `pointer-events: none` on `<body>`, so a frame must set `pointer-events: auto` to take a click. Stripe's popups set it. If the popup of another script does not, set it on the frame in your CSS.

A popup that shows page elements at the center of the viewport does not count, also when it holds a frame at another place. If the script can render its popup into an element that you choose, give it an element in the sheet.

An open sheet hides the rest of the page from assistive technology. That includes a popup that was on the page before the sheet opened. The sheet removes that `aria-hidden` from the popup when the page gets a focus event for the move into the popup. Firefox sends no such event when focus was in another frame or on `<body>`.

Your code still does two things:

- Close the sheet only after the popup closes. A payment script saves the `<body>` style and the `aria-hidden` state of the page when its popup opens. It puts them back when the popup closes. If the sheet closes in between, the page takes no clicks and a screen reader finds no content.
- Move focus when the script gives you the result. The browser does not return focus to the sheet when the popup closes.

The example runs `confirmWithBank`, a stand-in for a payment script. It does what Stripe.js does to the page:

- It puts a wrapper on `<body>` that fills the viewport above every layer.
- It shows the bank's page in a frame with its own origin.
- It calls `focus()` on the frame from the page.
- It saves the `<body>` style, and puts that style back when the popup closes.

Select **Save card**. In the bank's frame, select the code field and type a code. Press Escape in the frame to cancel the check: the popup closes, the sheet stays open, and focus moves to the result. While the popup is open, the sheet ignores each close request.

<Example name="components/overlays/sheet/third-party-popups" title="Sheet third-party popups example">

```tsx
import { Alert } from "@ngrok/mantle/alert";
import { Button } from "@ngrok/mantle/button";
import { Field } from "@ngrok/mantle/field";
import { Input } from "@ngrok/mantle/input";
import { Sheet } from "@ngrok/mantle/sheet";
import { useEffect, useRef, useState } from "react";

type ChallengeResult = "verified" | "canceled";

// The page of the bank. The frame has its own origin, so it reports the
// result to the page with a message.
function challengeDocument(nonce: string): string {
	return `<!doctype html>
<html lang="en">
	<meta charset="utf-8" />
	<title>Bank verification</title>
	<style>
		body { display: grid; min-height: 100vh; margin: 0; place-items: center; font: 14px/1.5 system-ui, sans-serif; }
		form { display: grid; box-sizing: border-box; gap: 12px; width: min(20rem, calc(100vw - 2rem)); padding: 24px; border-radius: 12px; background: white; color: #1f1f1f; }
		h1 { margin: 0; font-size: 16px; }
		input, button { padding: 8px 12px; border: 1px solid #8f8f8f; border-radius: 6px; font: inherit; }
		button[type="submit"] { background: #1f1f1f; color: white; }
	</style>
	<form>
		<h1>Verify your card</h1>
		<label for="code">Enter the code from your bank</label>
		<input id="code" inputmode="numeric" autocomplete="one-time-code" required />
		<button type="submit">Verify</button>
		<button type="button" id="cancel">Cancel</button>
	</form>
	<script nonce="${nonce}">
		const code = document.getElementById("code");
		const reply = (result) => parent.postMessage(result, "*");
		addEventListener("focus", () => code.focus());
		document.querySelector("form").addEventListener("submit", (event) => {
			event.preventDefault();
			reply("verified");
		});
		document.getElementById("cancel").addEventListener("click", () => reply("canceled"));
		addEventListener("keydown", (event) => {
			if (event.key === "Escape") {
				reply("canceled");
			}
		});
	</script>
</html>`;
}

// A stand-in for the script of a payment provider. It does to the page what
// Stripe.js does for a 3-D Secure challenge or a wallet sign-in.
function confirmWithBank(): Promise<ChallengeResult> {
	return new Promise((resolve) => {
		const popup = document.createElement("div");
		popup.style.display = "none";
		const frame = document.createElement("iframe");
		frame.title = "Bank verification";
		frame.sandbox.add("allow-scripts", "allow-forms");
		// Why the nonce: the docs site has a content security policy, and the
		// frame takes that policy from the page.
		frame.srcdoc = challengeDocument(document.querySelector("script")?.nonce ?? "");
		popup.append(frame);
		document.body.append(popup);

		frame.addEventListener(
			"load",
			() => {
				// The script saves the inline style of <body>, and puts it back on close.
				const bodyStyle = document.body.style.cssText;
				document.body.style.overflow = "hidden";
				// The wrapper fills the viewport above every layer. The frame turns
				// pointer events back on, because the open sheet turns them off on <body>.
				popup.style.cssText =
					"position: fixed; inset: 0; z-index: 2147483647; background: rgb(40 40 40 / 0.75);";
				frame.style.cssText =
					"position: absolute; left: 0; top: 0; width: 100%; height: 100%; border: 0; color-scheme: only light; pointer-events: auto;";
				// The script moves focus to its frame from the page.
				frame.focus();

				const onMessage = (event: MessageEvent) => {
					if (event.source !== frame.contentWindow) {
						return;
					}
					window.removeEventListener("message", onMessage);
					popup.remove();
					document.body.style.cssText = bodyStyle;
					resolve(event.data === "verified" ? "verified" : "canceled");
				};
				window.addEventListener("message", onMessage);
			},
			{ once: true },
		);
	});
}

// The result of the bank's check. `role="alert"` makes a screen reader
// announce it. It takes focus on mount, because the browser does not return
// focus to the sheet when the popup closes.
function ChallengeResultAlert({ result }: { result: ChallengeResult }) {
	const alertRef = useRef<HTMLDivElement>(null);
	useEffect(() => {
		alertRef.current?.focus();
	}, []);
	const isVerified = result === "verified";

	return (
		<Alert.Root
			intent={isVerified ? "success" : "warning"}
			ref={alertRef}
			role="alert"
			tabIndex={-1}
		>
			<Alert.Icon />
			<Alert.Content>
				<Alert.Title>{isVerified ? "Card verified" : "Card not verified"}</Alert.Title>
				<Alert.Description>
					{isVerified
						? "The bank approved the card."
						: "You canceled the check. Save the card again."}
				</Alert.Description>
			</Alert.Content>
		</Alert.Root>
	);
}

function Example() {
	const [isOpen, setIsOpen] = useState(false);
	const [status, setStatus] = useState<"idle" | "confirming" | ChallengeResult>("idle");

	return (
		<Sheet.Root
			open={isOpen}
			onOpenChange={(open) => {
				// Keep the sheet open until the popup closes. Focus can come back to
				// the sheet from the frame, and a close in between leaves the page
				// with no clicks.
				if (status === "confirming") {
					return;
				}
				setIsOpen(open);
				setStatus("idle");
			}}
		>
			<Sheet.Trigger asChild>
				<Button type="button" appearance="filled" intent="neutral">
					Add payment method
				</Button>
			</Sheet.Trigger>
			<Sheet.Content>
				<Sheet.Header>
					<Sheet.TitleGroup>
						<Sheet.Title>Add payment method</Sheet.Title>
						<Sheet.Actions>
							<Sheet.CloseIconButton />
						</Sheet.Actions>
					</Sheet.TitleGroup>
					<Sheet.Description>Your bank asks you to verify the card.</Sheet.Description>
				</Sheet.Header>
				<form
					className="contents"
					onSubmit={(event) => {
						event.preventDefault();
						setStatus("confirming");
						void confirmWithBank().then(setStatus);
					}}
				>
					<Sheet.Body className="space-y-4">
						<Field.Item name="cardholder">
							<Field.Label>Name on card</Field.Label>
							<Field.Control>
								<Input autoComplete="cc-name" defaultValue="Ada Lovelace" />
							</Field.Control>
						</Field.Item>
						<Field.Item name="card-number">
							<Field.Label>Card number</Field.Label>
							<Field.Control>
								<Input autoComplete="cc-number" defaultValue="4000 0027 6000 3184" />
							</Field.Control>
							<Field.Description>A test card that needs a 3-D Secure challenge.</Field.Description>
						</Field.Item>
						{(status === "verified" || status === "canceled") && (
							<ChallengeResultAlert result={status} />
						)}
					</Sheet.Body>
					<Sheet.Footer>
						<Sheet.Close asChild>
							<Button type="button" appearance="outlined" intent="neutral">
								Close
							</Button>
						</Sheet.Close>
						<Button
							type="submit"
							appearance="filled"
							intent="neutral"
							isLoading={status === "confirming"}
						>
							Save card
						</Button>
					</Sheet.Footer>
				</form>
			</Sheet.Content>
		</Sheet.Root>
	);
}
```

### With TanStack Form

Sheets often host small create/edit forms. Use [TanStack Form](https://tanstack.com/form) with [`Field`](/components/forms/field) for label, description, and error wiring. `Sheet.Content` is a flex column, so wrap `Sheet.Body` and `Sheet.Footer` in a `display: contents` form; the footer's submit button participates in the form while the body keeps its scrollable layout. Close the sheet from the form's `onSubmit` (it only runs once validation passes) and reset the form when the sheet closes so a cancelled draft doesn't leak into the next open.

<Example name="components/overlays/sheet/with-tanstack-form" title="Sheet With TanStack Form example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { Field, toErrorMessages } from "@ngrok/mantle/field";
import { Input } from "@ngrok/mantle/input";
import { Sheet } from "@ngrok/mantle/sheet";
import { TextArea } from "@ngrok/mantle/text-area";
import { useForm } from "@tanstack/react-form";
import { useState } from "react";
import { z } from "zod";

const formSchema = z.object({
	name: z.string().min(1, "Name your API key."),
	note: z.string().max(280, "Keep the note under 280 characters."),
});

function Example() {
	const [open, setOpen] = useState(false);
	const form = useForm({
		defaultValues: {
			name: "",
			note: "",
		},
		validators: {
			onSubmit: formSchema,
		},
		onSubmit: ({ value }) => {
			// Handle the create with `value`, then close the sheet
			handleOpenChange(false);
		},
	});

	const handleOpenChange = (nextOpen: boolean) => {
		setOpen(nextOpen);
		if (!nextOpen) {
			form.reset();
		}
	};

	return (
		<Sheet.Root open={open} onOpenChange={handleOpenChange}>
			<Sheet.Trigger asChild>
				<Button type="button" appearance="filled" intent="neutral">
					New API key
				</Button>
			</Sheet.Trigger>
			<Sheet.Content>
				<Sheet.Header>
					<Sheet.TitleGroup>
						<Sheet.Title>New API key</Sheet.Title>
						<Sheet.Actions>
							<Sheet.CloseIconButton />
						</Sheet.Actions>
					</Sheet.TitleGroup>
					<Sheet.Description>
						Create a key for programmatic access to the ngrok API.
					</Sheet.Description>
				</Sheet.Header>
				<form
					className="contents"
					onSubmit={(event) => {
						event.preventDefault();
						event.stopPropagation();
						void form.handleSubmit();
					}}
				>
					<Sheet.Body className="space-y-4">
						<form.Field name="name">
							{(field) => (
								<Field.Item name={field.name}>
									<Field.Label>Name</Field.Label>
									<Field.Control>
										<Input
											placeholder="production-deploys"
											value={field.state.value}
											onBlur={field.handleBlur}
											onChange={(event) => field.handleChange(event.target.value)}
										/>
									</Field.Control>
									<Field.Errors messages={toErrorMessages(field.state.meta.errors)} />
								</Field.Item>
							)}
						</form.Field>
						<form.Field name="note">
							{(field) => (
								<Field.Item name={field.name}>
									<Field.Label>Note</Field.Label>
									<Field.Control>
										<TextArea
											placeholder="What is this key used for?"
											value={field.state.value}
											onBlur={field.handleBlur}
											onChange={(event) => field.handleChange(event.target.value)}
										/>
									</Field.Control>
									<Field.Description>
										Optional. Help your team know where this key is used.
									</Field.Description>
									<Field.Errors messages={toErrorMessages(field.state.meta.errors)} />
								</Field.Item>
							)}
						</form.Field>
					</Sheet.Body>
					<Sheet.Footer>
						<Sheet.Close asChild>
							<Button type="button" appearance="outlined" intent="neutral">
								Cancel
							</Button>
						</Sheet.Close>
						<Button type="submit" appearance="filled" intent="neutral">
							Create key
						</Button>
					</Sheet.Footer>
				</form>
			</Sheet.Content>
		</Sheet.Root>
	);
}
```

## Composition

Compose the parts of a `Sheet` together to build your own:

```text showLineNumbers=false
Sheet.Root
├── Sheet.Trigger
└── Sheet.Content
    ├── Sheet.Header
    │   ├── Sheet.TitleGroup
    │   │   ├── Sheet.Title
    │   │   └── Sheet.Actions
    │   └── Sheet.Description
    ├── Sheet.Body
    └── Sheet.Footer
        └── Sheet.Close
```

## Polymorphism

`Sheet.Trigger`, `Sheet.Close`, `Sheet.Content`, `Sheet.Title`, `Sheet.Description`, and `Sheet.CloseIconButton` accept `asChild`, which renders your single child instead of the part's default element while keeping its styling and behavior.

`Sheet.Trigger asChild` is the most common: it makes your own `Button` open the sheet rather than nesting a button inside one. `Sheet.Close asChild` lets any element dismiss the sheet, which is handy for a "Cancel" button in `Sheet.Footer`, and `Sheet.Title asChild` adjusts the heading level to fit the page outline.

`Sheet.Root` renders no DOM of its own, so it takes no `asChild`. `Sheet.Header`, `Sheet.Body`, `Sheet.Footer`, `Sheet.TitleGroup`, and `Sheet.Actions` are layout containers that do not currently accept it.

## API Reference

The `Sheet` components are built on top of [Radix Dialog](https://www.radix-ui.com/primitives/docs/components/dialog).

### Sheet.Root

The root component for a `Sheet`. Should compose the `Sheet.Trigger` and `Sheet.Content`. Acts as a stateful provider for the Sheet's open/closed state.

Every `Sheet` part reads a dialog scope of its own, so it binds to the nearest `Sheet.Root` and never to a `Dialog.Root`. The reverse holds too: a `Dialog.Trigger` or `Command.SearchTrigger` inside `Sheet.Content` reaches the `Dialog.Root` or `Command.DialogRoot` above the sheet, not the sheet. A `Dialog.Close` inside a sheet with no `Dialog.Root` above it throws Radix's "must be used within `Dialog`"; use `Sheet.Close` to close a sheet.

`Sheet` renders its floating layer at Tailwind `z-60`, Mantle's overlay tier, above every float (`z-50`). Floats composed inside the content portal into the positioner (`data-slot="sheet-positioner"`) and paint above the content. When multiple overlays are open, the most recently mounted overlay renders on top.

All props from Radix [Dialog.Root](https://www.radix-ui.com/primitives/docs/components/dialog#root).

### Sheet.Trigger

The button trigger for a `Sheet`. Should be rendered as a child of the `Sheet` component. Renders an unstyled `button` by default, but can be customized with the `asChild` prop.

Opens the nearest `Sheet.Root`. It never opens a `Dialog.Root`, and a `Dialog.Trigger` inside the sheet never opens the sheet.

All props from Radix [Dialog.Trigger](https://www.radix-ui.com/primitives/docs/components/dialog#trigger).

### Sheet.Close

The close button for a `Sheet`. Should be rendered as a child of the `Sheet.Content` component. Usually contained within the `Sheet.Footer` component. Renders an unstyled `button` by default, but can be customized with the `asChild` prop.

Closes the nearest `Sheet.Root`. It never closes a `Dialog.Root`, and a `Dialog.Close` inside the sheet never closes the sheet.

Radix [Dialog.Close](https://www.radix-ui.com/primitives/docs/components/dialog#close) props.

### Sheet.Content

The main container for a `Sheet`. Should be rendered as a child of the `Sheet` component. Renders on top of the overlay backdrop. Should contain the `Sheet.Header`, `Sheet.Body`, and `Sheet.Footer`.

`Sheet.Content` renders its floating layer at Tailwind `z-60`, Mantle's overlay tier, above every float (`z-50`). Floats composed inside the content portal into the positioner (`data-slot="sheet-positioner"`) and paint above the content. When multiple overlays are open, the most recently mounted overlay renders on top.

`Sheet.Content` renders inside a positioner element (`data-slot="sheet-positioner"`) that lays out the content and receives floats portaled from inside the sheet. The full stacking contract lives at [Stacking Layers](/base/stacking-layers).

All props from Radix [Dialog.Content](https://www.radix-ui.com/primitives/docs/components/dialog#content), plus:

| Prop              | Type                       | Default          | Description                                                                                                                                                                                                                                                                   |
| ----------------- | -------------------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

### Sheet.CloseIconButton

An icon button that closes the `Sheet` when clicked. Should be rendered within the `Sheet.Header` as a child of `Sheet.Actions`.

| Prop          | Type                                           | Default         | Description                                                                  |
| ------------- | ---------------------------------------------- | --------------- | ---------------------------------------------------------------------------- |
| `appearance?` | `"filled"` \| `"ghost"` \| `"outlined"`        | `"ghost"`       | The visual style of the close icon button.                                   |
| `intent?`     | `"neutral"`                                    | `"neutral"`     | The tone of the close icon button. `IconButton` draws the neutral tone only. |
| `size?`       | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"` | `"md"`          | The size of the close icon button.                                           |
| `label?`      | `string`                                       | `"Close Sheet"` | The accessible label for the close button. Important for screen readers.     |

All remaining props (except `icon`, which is fixed to an X icon) forward to the [Mantle IconButton](/components/actions/icon-button).
