# Popover

Displays rich content in a portal, triggered by a button.

<Example name="components/overlays/popover/overview" title="Popover example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { Input } from "@ngrok/mantle/input";
import { Popover } from "@ngrok/mantle/popover";

<Popover.Root>
	<Popover.Trigger asChild>
		<Button type="button" appearance="filled" intent="neutral">
			Open popover
		</Button>
	</Popover.Trigger>
	<Popover.Content aria-labelledby="popover-dimensions" preferredWidth="max-w-96">
		<form
			className="grid gap-4"
			onSubmit={(event) => {
				event.preventDefault();
			}}
		>
			<div className="space-y-2">
				<h4 id="popover-dimensions" className="font-medium leading-none">
					Dimensions
				</h4>
				<p className="text-sm text-gray-700">Set the dimensions for the layer.</p>
			</div>
			<div className="grid gap-2">
				<div className="grid grid-cols-3 items-center gap-4">
					<label htmlFor="popover-width">Width</label>
					<Input id="popover-width" defaultValue="100%" className="col-span-2 h-8" />
				</div>
				<div className="grid grid-cols-3 items-center gap-4">
					<label htmlFor="popover-maxWidth">Max width</label>
					<Input id="popover-maxWidth" defaultValue="300px" className="col-span-2 h-8" />
				</div>
				<div className="grid grid-cols-3 items-center gap-4">
					<label htmlFor="popover-height">Height</label>
					<Input id="popover-height" defaultValue="25px" className="col-span-2 h-8" />
				</div>
				<div className="grid grid-cols-3 items-center gap-4">
					<label htmlFor="popover-maxHeight">Max height</label>
					<Input id="popover-maxHeight" defaultValue="none" className="col-span-2 h-8" />
				</div>
			</div>
		</form>
	</Popover.Content>
</Popover.Root>;
```

</Example>

## When to use

- Show interactive floating content anchored to a trigger, such as a form, a menu of actions, filters, or settings.
- Prefer [`Tooltip`](/components/overlays/tooltip) for a short, non-interactive label on a control (for example, the purpose of an icon-only button).
- Prefer [`HoverCard`](/components/overlays/hover-card) for a sighted-only preview of content that already lives behind a link.
- Prefer [`DropdownMenu`](/components/overlays/dropdown-menu) when the content is a list of actions.
- Prefer [`Dialog`](/components/overlays/dialog) when the task needs a modal window that blocks the page.

## Presentation

Set `presentation="auto"` on `Popover.Root` when the popover holds a small task, such as a short form. On a phone (a viewport below `sm` with a touch pointer), the content opens in a [`Drawer`](/components/overlays/drawer) from the bottom edge, which closes on a swipe down, where a thumb reaches the fields and the actions. Everywhere else it is a popover. The choice happens each time the popover opens and holds until it closes, so a rotated phone keeps what the user typed.

Keep the default for a short list to pick from: a list that jumps to the bottom of the screen moves away from the control it belongs to. `DropdownMenu`, `Select`, and `Combobox` have no drawer.

The drawer code loads at idle, and only on a phone, so a desktop page never fetches it. A tap before it loads opens a popover. Style the two shapes with `data-[presentation=drawer]:`. A `Sandbar` slides away while the drawer is open and comes back when it closes.

<Example name="components/overlays/popover/presentation" title="Popover presentation example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { Input } from "@ngrok/mantle/input";
import { Popover } from "@ngrok/mantle/popover";

<Popover.Root presentation="auto">
	<Popover.Trigger asChild>
		<Button type="button" appearance="outlined" intent="neutral">
			Add reminder
		</Button>
	</Popover.Trigger>
	<Popover.Content aria-labelledby="popover-reminder" preferredWidth="max-w-80">
		<form
			className="grid gap-4"
			onSubmit={(event) => {
				event.preventDefault();
			}}
		>
			<div className="space-y-1">
				<h4 id="popover-reminder" className="font-medium leading-none">
					New reminder
				</h4>
				<p className="text-body text-sm">We notify you at the time you pick.</p>
			</div>
			<div className="grid gap-2">
				<label htmlFor="popover-reminder-text" className="text-sm">
					Remind me to
				</label>
				<Input id="popover-reminder-text" defaultValue="Send the Q3 roadmap" />
			</div>
			<div className="flex justify-end gap-2">
				<Popover.Close asChild>
					<Button type="button" appearance="outlined" intent="neutral">
						Cancel
					</Button>
				</Popover.Close>
				<Popover.Close asChild>
					<Button type="button" appearance="filled" intent="neutral">
						Save
					</Button>
				</Popover.Close>
			</div>
		</form>
	</Popover.Content>
</Popover.Root>;
```

</Example>

## Arrow

Render `Popover.Arrow` as a child of `Popover.Content` when the popover explains one specific control and needs a tip pointing at it. The arrow moves to the edge that faces the anchor, so it stays centered on the anchor when the content shifts or flips. A hand-rolled tip is a fixed offset and drifts off the anchor as soon as the content moves. The arrow's fill and border repaint `Popover.Content`'s own edge across its base, so the two edges read as one line. The tip also casts its own shadow, because `shadow-md` on `Popover.Content` stops at that content's border and an unshadowed tip reads as pasted on. That shadow is clipped at the base, so it never darkens the content's interior.

`Popover.Arrow` takes no `asChild`. The shape is two layers (a filled polygon, plus a polyline that strokes the slanted edges only), and a swapped element loses the border. Restyle it with `className` instead: `fill-*` for the surface and a `stroke-*` on the arrow's `polyline` child for the edge, since the arrow is an `svg` where `bg-*` paints nothing.

<Example name="components/overlays/popover/arrow" title="Popover arrow example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { Popover } from "@ngrok/mantle/popover";

<Popover.Root>
	<Popover.Trigger asChild>
		<Button type="button" appearance="filled" intent="neutral">
			What moved?
		</Button>
	</Popover.Trigger>
	<Popover.Content side="right" preferredWidth="max-w-64">
		<Popover.Arrow />
		<p className="text-sm">Products moved up here.</p>
	</Popover.Content>
</Popover.Root>;
```

</Example>

## Layering and z-index

`Popover.Content` is a native [`popover`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/popover) in the browser's top layer, so it paints above the page with no `z-index`. It portals into the content of the open `Dialog`, `AlertDialog`, `Sheet`, or `Popover` that holds it, else into `document.body`. A `Select`, `DropdownMenu`, or other float inside it portals into it. It hides while an overlay that does not hold it is open, and shows again when that overlay closes. See [Stacking layers](/base/stacking-layers).

`Popover` does not render a backdrop by default. Modal layers such as `Dialog`, `Sheet`, and `AlertDialog` do render backdrops, so stacking those layers compounds the dim and blur effect on the layers underneath.

## Composition

Compose the parts of a `Popover` together to build your own:

```text showLineNumbers=false
Popover.Root
├── Popover.Trigger
├── Popover.Anchor
└── Popover.Content
    ├── Popover.Arrow
    └── Popover.Close
```

## Focus and dismissal

A `Popover` is a non-modal dialog. Focus moves to the first focusable element in the content on open. `Escape` closes it and returns focus to the trigger. A press or a focus move outside closes it and leaves focus where the user put it. The page (body and any scroll containers) continues to scroll normally. For a task that must block the page, use [`Dialog`](/components/overlays/dialog).

## API Reference

The `Popover` components are built on the native [popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API). A script places the content next to its trigger. Where the browser has no popover API, the content is a fixed box at `z-50`.

### Popover.Root

The root, stateful component that manages the open/closed state of the popover.

| Prop            | Type                      | Default     | Description                                                                                                                                                           |
| :-------------- | :------------------------ | :---------- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `defaultOpen?`  | `boolean`                 | `false`     | The open state when initially rendered. Use when you do not need to control the state.                                                                                |
| `open?`         | `boolean`                 |             | Controlled open state. Must be used with `onOpenChange`.                                                                                                              |
| `onOpenChange?` | `(open: boolean) => void` |             | Event handler called when the open state changes.                                                                                                                     |
| `presentation?` | `"popover" \| "auto"`     | `"popover"` | How the popover presents. `"auto"` opens a modal drawer from the bottom edge on a phone (below `sm`, touch pointer) and a popover elsewhere. It decides at each open. |

### Popover.Trigger

The button that toggles the popover.

All props of a `<button>`. It sets `aria-haspopup="dialog"`, `aria-expanded`, and, while open, `aria-controls`.

| Prop       | Type      | Default | Description                                                           |
| :--------- | :-------- | :------ | :-------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Compose onto an alternative element type or your own React component. |

### Popover.Content

The content to render inside the popover. Appears in a portal with styling and animations.

It is a `role="dialog"` named by its trigger, such as "Open popover". Pass `aria-label` or `aria-labelledby`, such as the `id` of a heading in the content, to give it a name of its own.

`Popover.Content` is `position: fixed`, so an absolutely-positioned child of the content anchors to the content. It sets the CSS variables `--anchor-width` (the width of the anchor) and `--available-height` (the room between the anchor and the edge of the viewport), for example `w-(--anchor-width)`.

All props of a `<div>`, plus:

| Prop                    | Type                                     | Default      | Description                                                                                                                                                                                                                                 |
| :---------------------- | :--------------------------------------- | :----------- | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `preferredWidth?`       | `` `max-w-${string}` ``                  | `"max-w-72"` | The preferred width as a Tailwind `max-w-` class.                                                                                                                                                                                           |
| `side?`                 | `"top" \| "right" \| "bottom" \| "left"` | `"bottom"`   | The preferred side of the anchor. The content flips to the opposite side when only that side fits.                                                                                                                                          |
| `sideOffset?`           | `number`                                 | `4`          | The distance in pixels from the anchor.                                                                                                                                                                                                     |
| `align?`                | `"start" \| "center" \| "end"`           | `"center"`   | The alignment against the anchor. The content shifts along the side to stay in the viewport.                                                                                                                                                |
| `onOpenAutoFocus?`      | `(event: Event) => void`                 |              | Runs before focus moves into the content on open. Call `event.preventDefault()` to keep focus where it is.                                                                                                                                  |
| `onCloseAutoFocus?`     | `(event: Event) => void`                 |              | Runs before focus returns to the trigger on close. Call `event.preventDefault()` to move focus yourself.                                                                                                                                    |
| `onEscapeKeyDown?`      | `(event: KeyboardEvent) => void`         |              | Runs on `Escape`. Call `event.preventDefault()` to keep the popover open.                                                                                                                                                                   |
| `onPointerDownOutside?` | `(event: CustomEvent) => void`           |              | Runs when a press starts outside. `event.detail.originalEvent` is the pointer event. Call `event.preventDefault()` to keep the popover open. Otherwise the popover closes when the press ends outside, so a touch scroll does not close it. |
| `onFocusOutside?`       | `(event: CustomEvent) => void`           |              | Runs when focus moves outside. `event.detail.originalEvent` is the focus event. Call `event.preventDefault()` to keep the popover open.                                                                                                     |
| `onInteractOutside?`    | `(event: CustomEvent) => void`           |              | Runs for both. Call `event.preventDefault()` to keep the popover open.                                                                                                                                                                      |

| Data Attribute              | Value                                          | Description                                                                                                                                                               |
| --------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `data-slot`                 | `"popover-content"`                            | On the content, with any composing part's chain ahead of it.                                                                                                              |
| `data-open`                 | present while open                             | Presence-only. Absent while the exit transition plays.                                                                                                                    |
| `data-side`                 | `"top"` \| `"right"` \| `"bottom"` \| `"left"` | The side of the anchor the content resolved to. Popover presentation only.                                                                                                |
| `data-presentation`         | `"popover"` \| `"drawer"`                      | How this open presents. Style the two shapes with `data-[presentation=drawer]:`.                                                                                          |
| `data-closing`              | present while the exit plays                   | Presence-only. Drawer presentation only. Drives the slide out.                                                                                                            |
| `data-mantle-modal-content` | `""`                                           | Drawer presentation only. Floats and an enclosing dialog find the panel by it.                                                                                            |
| `data-slot` (positioner)    | `"drawer-positioner"`                          | Drawer presentation only. On the `<dialog>` of the `Drawer` around the content, which carries `role="dialog"`, the name, `data-open`, `data-closing`, and `data-overlay`. |
| `data-mantle-scroll-lock`   | present while a drawer is open                 | Presence-only. On `<html>`. The page stops scrolling.                                                                                                                     |
| `data-overlay`              | `""`                                           | Drawer presentation only. On the `<dialog>` positioner. A press on the backdrop targets it.                                                                               |

### Popover.Anchor

An optional element to position the `Popover.Content` against. If not used, the content will position alongside the `Popover.Trigger`.

All props of a `<div>`.

| Prop       | Type      | Default | Description                                                           |
| :--------- | :-------- | :------ | :-------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Compose onto an alternative element type or your own React component. |

### Popover.Close

A button that closes an open popover.

All props of a `<button>`.

| Prop       | Type      | Default | Description                                                           |
| :--------- | :-------- | :------ | :-------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Compose onto an alternative element type or your own React component. |

### Popover.Arrow

An optional tip that points from `Popover.Content` at its anchor. Render it as a direct child of `Popover.Content`. It renders an `svg`, so `fill-*` paints the surface and `bg-*` paints nothing.

It takes no `asChild`: the shape is a filled polygon plus a polyline that strokes the slanted edges, and a swapped element loses the border that continues `Popover.Content`'s edge.

All props of an `svg` except `children`, plus:

| Prop        | Type     | Default | Description                                                                                                                                                                               |
| :---------- | :------- | :------ | :---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `width?`    | `number` | `14`    | The width of the arrow in pixels.                                                                                                                                                         |
| `height?`   | `number` | `7`     | The height of the arrow in pixels. It adds to `sideOffset`, so the tip lands `sideOffset` pixels from the anchor.                                                                         |
| `className` | `string` |         | Classes for the `svg`. Reach for `fill-*` for the surface, and target the `polyline` child for the edge: `[&>polyline]:…`. The part already sets `filter` and `clip-path` for its shadow. |

| Data Attribute     | Value | Description                                                                                       |
| ------------------ | ----- | ------------------------------------------------------------------------------------------------- |
| `data-float-arrow` | `""`  | On the `<span>` around the arrow's `<svg>`. The float moves it to the edge that faces the anchor. |
