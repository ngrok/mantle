# Dropdown Menu

Displays a menu to the user (such as a set of actions or functions), triggered by a button.

<Example name="components/overlays/dropdown-menu/overview" title="Dropdown Menu example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { DropdownMenu } from "@ngrok/mantle/dropdown-menu";
import { Icon } from "@ngrok/mantle/icon";
import { Tooltip } from "@ngrok/mantle/tooltip";
import { DesktopIcon } from "@phosphor-icons/react/Desktop";
import { GearIcon } from "@phosphor-icons/react/Gear";
import { MoonIcon } from "@phosphor-icons/react/Moon";
import { SignOutIcon } from "@phosphor-icons/react/SignOut";
import { SunIcon } from "@phosphor-icons/react/Sun";
import { useState } from "react";

function Example() {
	const [selectedTheme, setSelectedTheme] = useState("system");
	const [enableNotifications, setEnableNotifications] = useState(false);

	return (
		<DropdownMenu.Root>
			<DropdownMenu.Trigger asChild>
				<Button type="button" appearance="filled" intent="neutral">
					Open menu
				</Button>
			</DropdownMenu.Trigger>
			<DropdownMenu.Content>
				<DropdownMenu.Label>corby.pickles@ngork.com</DropdownMenu.Label>
				<DropdownMenu.Separator />
				<DropdownMenu.RadioGroup
					value={selectedTheme}
					onValueChange={(value) => {
						setSelectedTheme(value);
					}}
				>
					<DropdownMenu.RadioItem value="system">
						<Icon svg={<DesktopIcon />} />
						System preference
					</DropdownMenu.RadioItem>
					<DropdownMenu.RadioItem value="light">
						<Icon svg={<SunIcon />} />
						Light mode
					</DropdownMenu.RadioItem>
					<DropdownMenu.RadioItem value="dark">
						<Icon svg={<MoonIcon />} />
						Dark mode
					</DropdownMenu.RadioItem>
				</DropdownMenu.RadioGroup>
				<DropdownMenu.Separator />
				<Tooltip.Root>
					<Tooltip.Trigger asChild>
						<DropdownMenu.Item className="flex items-center gap-2" disabled>
							<Icon svg={<GearIcon />} />
							User settings
						</DropdownMenu.Item>
					</Tooltip.Trigger>
					<Tooltip.Content side="left">Only winners get user settings.</Tooltip.Content>
				</Tooltip.Root>
				<DropdownMenu.Separator />
				<DropdownMenu.CheckboxItem
					checked={enableNotifications}
					onCheckedChange={(value) => {
						setEnableNotifications(value);
					}}
				>
					Enable notifications
				</DropdownMenu.CheckboxItem>
				<DropdownMenu.Group>
					<DropdownMenu.Item>Team</DropdownMenu.Item>
					<DropdownMenu.Sub>
						<DropdownMenu.SubTrigger>Invite users</DropdownMenu.SubTrigger>
						<DropdownMenu.SubContent>
							<DropdownMenu.Item>Email</DropdownMenu.Item>
							<DropdownMenu.Item>Message</DropdownMenu.Item>
							<DropdownMenu.Separator />
							<DropdownMenu.Item>More...</DropdownMenu.Item>
						</DropdownMenu.SubContent>
					</DropdownMenu.Sub>
					<DropdownMenu.Item>
						New team
						<DropdownMenu.Shortcut>⌘+T</DropdownMenu.Shortcut>
					</DropdownMenu.Item>
				</DropdownMenu.Group>
				<DropdownMenu.Separator />
				<DropdownMenu.Item className="flex items-center gap-2">
					<Icon svg={<SignOutIcon />} />
					Log out
				</DropdownMenu.Item>
			</DropdownMenu.Content>
		</DropdownMenu.Root>
	);
}
```

</Example>

## When to use

- Show a menu of actions or options when the user clicks a button.
- Prefer [`Select`](/components/forms/select) when the user picks one value for a form field.
- Prefer [`SplitButton`](/components/actions/split-button) when a default action runs on one click and the menu holds its alternatives.
- Prefer [`Command`](/components/navigation/command) when the user searches many actions or pages from the keyboard.
- Prefer [`Popover`](/components/overlays/popover) when the floating content is a small form or other content, not a menu.

## Layering and z-index

`DropdownMenu.Content` and `DropdownMenu.SubContent` are native [`popover`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/popover) elements in the browser's top layer, so they paint above the page with no `z-index`. They portal into the content of the open `Dialog`, `AlertDialog`, `Sheet`, or `Popover` that holds them, else into `document.body`. A `Popover`, `Select`, or other float that an item opens portals into the menu, so it takes focus and input. The menu closes when an overlay that does not hold it opens. See [Stacking layers](/base/stacking-layers).

`DropdownMenu` does not render a backdrop by default. Modal layers such as `Dialog`, `Sheet`, and `AlertDialog` do render backdrops, so stacking those layers compounds the dim and blur effect on the layers underneath.

## Composition

Compose the parts of a `DropdownMenu` together to build your own:

```text showLineNumbers=false
DropdownMenu.Root
├── DropdownMenu.Trigger
└── DropdownMenu.Content
    ├── DropdownMenu.Group
    │   ├── DropdownMenu.Label
    │   ├── DropdownMenu.Item
    │   │   └── DropdownMenu.Shortcut
    │   ├── DropdownMenu.CheckboxItem
    │   └── DropdownMenu.RadioGroup
    │       └── DropdownMenu.RadioItem
    ├── DropdownMenu.Separator
    └── DropdownMenu.Sub
        ├── DropdownMenu.SubTrigger
        └── DropdownMenu.SubContent
```

## Polymorphism

`asChild` renders the part's single child instead of its default element, and forwards class names, `data-*`
attributes, and `ref` onto that child. These parts take it:

| Part                        | Reach for it when                                                    |
| --------------------------- | -------------------------------------------------------------------- |
| `DropdownMenu.Trigger`      | The trigger is a `Button`, an `IconButton`, or your own control.     |
| `DropdownMenu.Content`      | The panel needs its own element to carry layout or a motion wrapper. |
| `DropdownMenu.SubContent`   | The same, for a submenu panel.                                       |
| `DropdownMenu.Item`         | The item navigates, so it must render an `<a>` or a router `Link`.   |
| `DropdownMenu.CheckboxItem` | The same, for a choice a URL carries.                                |
| `DropdownMenu.RadioItem`    | The same, for one choice out of a URL-driven set.                    |
| `DropdownMenu.SubTrigger`   | The submenu opener must be your own element.                         |
| `DropdownMenu.Label`        | The label needs a heading element for the document outline.          |
| `DropdownMenu.Group`        | The group needs its own element.                                     |
| `DropdownMenu.RadioGroup`   | The same, for a radio group.                                         |
| `DropdownMenu.Separator`    | The divider must be a specific element, such as an `<hr>`.           |

`DropdownMenu.SubTrigger`, `DropdownMenu.CheckboxItem`, and `DropdownMenu.RadioItem` each render a second
element beside your children: the submenu caret, or the check indicator. Under `asChild`, the part merges onto
your single child as the item element and moves the label span and that element inside it, so the
[translation guarantee](/browser-translation) holds on both paths.

## Keyboard

The menu follows the [WAI-ARIA menu button pattern](https://www.w3.org/WAI/ARIA/apg/patterns/menu-button/). Items take focus with a roving `tabindex`, so `Tab` does not move between them.

| Key                               | Action                                                                                                                                                      |
| :-------------------------------- | :---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Enter`, `Space`                  | On the trigger, opens the menu on its first item. On an item, selects it.                                                                                   |
| `ArrowDown`, `ArrowUp`            | On the trigger, opens the menu on its first or last item. In the menu, moves to the next or previous item and skips disabled items.                         |
| `Home`, `End`                     | Moves to the first or last item.                                                                                                                            |
| `ArrowRight` (`ArrowLeft` in RTL) | On a `SubTrigger`, opens its submenu on the first item.                                                                                                     |
| `ArrowLeft` (`ArrowRight` in RTL) | In a submenu, closes it and returns focus to its `SubTrigger`.                                                                                              |
| `Escape`                          | Closes the whole menu and returns focus to the trigger.                                                                                                     |
| A printable character             | Moves to the next item whose text starts with the characters typed in the last second. The same character again moves through the items that start with it. |

## API Reference

The `DropdownMenu` components are built on the native [popover API](https://developer.mozilla.org/en-US/docs/Web/API/Popover_API). A script places the menu next to its trigger. Where the browser has no popover API, the menu is a fixed box at `z-50`.

### DropdownMenu.Root

The root, stateful component that manages the open/closed state of the dropdown menu.

| Prop            | Type                      | Default | Description                                                                                                                                                                                                                                                                                                                |
| :-------------- | :------------------------ | :------ | :------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `open?`         | `boolean`                 |         | The controlled open state of the dropdown menu. Must be used in conjunction with `onOpenChange`.                                                                                                                                                                                                                           |
| `onOpenChange?` | `(open: boolean) => void` |         | Event handler called when the open state of the dropdown menu changes.                                                                                                                                                                                                                                                     |
| `defaultOpen?`  | `boolean`                 | `false` | The open state of the dropdown menu when it is initially rendered. Use when you do not need to control its open state.                                                                                                                                                                                                     |
| `dir?`          | `"ltr"` \| `"rtl"`        |         | The reading direction of submenus when applicable.                                                                                                                                                                                                                                                                         |
| `modal?`        | `boolean`                 | `false` | When `true`, the rest of the page is `inert` while the menu is open: a pointer, focus, or screen reader reaches only the trigger and the menu. By default the page stays live, as with a native popover. A press outside closes the menu, and its primary click (left button, no Ctrl) does not activate what is under it. |

### DropdownMenu.Trigger

The trigger button that opens the dropdown menu. It opens on a pointer press, so a press, drag, and release on an item selects that item.

All props of a `<button>`. It sets `aria-haspopup="menu"`, `aria-expanded`, `data-state`, and, while open, `aria-controls`.

| Prop       | Type      | Default | Description                                                                          |
| :--------- | :-------- | :------ | :----------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose the trigger functionality onto your own component. |

### DropdownMenu.Content

The container for the dropdown menu content. Appears in a portal with scrolling and animations. It has `role="menu"` and takes its name from the trigger.

`DropdownMenu.Content` is `position: fixed`. It sets the CSS variables `--anchor-width` (the width of the trigger) and `--available-height` (the room between the trigger and the edge of the viewport). Its height is at most `--available-height`, and it scrolls past that.

All props of a `<div>`, plus:

| Prop                    | Type                                                            | Default    | Description                                                                                                 |
| :---------------------- | :-------------------------------------------------------------- | :--------- | :---------------------------------------------------------------------------------------------------------- |
| `width?`                | `"trigger"` \| `"content"`                                      |            | `trigger` sets the menu to the width of the trigger. `content` uses the intrinsic width of the items.       |
| `side?`                 | `"top" \| "right" \| "bottom" \| "left"`                        | `"bottom"` | The preferred side of the trigger. The menu flips to the opposite side when only that side fits.            |
| `sideOffset?`           | `number`                                                        | `8`        | The distance in pixels from the trigger.                                                                    |
| `align?`                | `"start" \| "center" \| "end"`                                  | `"center"` | The alignment against the trigger. The menu shifts along the side to stay in the viewport.                  |
| `loop?`                 | `boolean`                                                       | `true`     | When `true`, `ArrowDown` on the last item moves to the first, and `ArrowUp` on the first moves to the last. |
| `onCloseAutoFocus?`     | `(event: Event) => void`                                        |            | Runs before focus returns to the trigger on close. Call `event.preventDefault()` to move focus yourself.    |
| `onEscapeKeyDown?`      | `(event: KeyboardEvent) => void`                                |            | Runs on `Escape`. Call `event.preventDefault()` to keep the menu open.                                      |
| `onPointerDownOutside?` | `(event: PointerDownOutsideEvent) => void`                      |            | Runs when a pointer press starts outside the menu. Call `event.preventDefault()` to keep it open.           |
| `onFocusOutside?`       | `(event: FocusOutsideEvent) => void`                            |            | Runs when focus moves outside the menu. Call `event.preventDefault()` to keep it open.                      |
| `onInteractOutside?`    | `(event: PointerDownOutsideEvent \| FocusOutsideEvent) => void` |            | Runs for both an outside press and an outside focus move. Call `event.preventDefault()` to keep it open.    |

#### Data attributes

| Data Attribute | Value                                    | Description                             |
| :------------- | :--------------------------------------- | :-------------------------------------- |
| `data-state`   | `"open"` \| `"closed"`                   | Whether the menu is open.               |
| `data-side`    | `"top" \| "right" \| "bottom" \| "left"` | The side the menu is on after it flips. |
| `data-align`   | `"start" \| "center" \| "end"`           | The `align` the menu takes.             |

### DropdownMenu.Item

A standard item in the dropdown menu that can be selected or activated.

| Prop         | Type                     | Default | Description                                                                                                                 |
| :----------- | :----------------------- | :------ | :-------------------------------------------------------------------------------------------------------------------------- |
| `inset?`     | `boolean`                |         | When `true`, adds left padding to align with items that have icons.                                                         |
| `disabled?`  | `boolean`                |         | When `true`, prevents the user from interacting with the item.                                                              |
| `onSelect?`  | `(event: Event) => void` |         | Event handler called when the user selects an item (via mouse or key). Call `event.preventDefault()` to keep the menu open. |
| `textValue?` | `string`                 |         | The text that typeahead matches. Defaults to the text content of the item.                                                  |

### DropdownMenu.CheckboxItem

A menu item with a checkbox that can be controlled or uncontrolled.

`children` render inside a `<span data-slot="dropdown-menu-checkbox-item-label">`. The check indicator is a permanent element sibling, so without the span a bare text label is never a lone child: a browser translation engine reparents that text node, and the removal React runs when the label changes shape or goes away throws. The span is `display: contents`, so an icon and its label stay flex items of the item and keep its `gap`. [Browser translation](/browser-translation) covers the mechanism and the rules your own components need.

An icon you pass as a child is now a grandchild of the item, so a `[&>svg]` class of your own no longer reaches it. Match the part's own variant instead: `[&>[data-slot=dropdown-menu-checkbox-item-label]>svg]:size-4`. A `[&_svg]` class or a class on the icon itself loses to the item's default, which carries one more attribute selector.

All props of `DropdownMenu.Item`, plus:

| Prop               | Type                           | Default | Description                                                                                            |
| :----------------- | :----------------------------- | :------ | :----------------------------------------------------------------------------------------------------- |
| `checked?`         | `boolean` \| `"indeterminate"` |         | The controlled checked state of the item. Must be used with `onCheckedChange`.                         |
| `defaultChecked?`  | `boolean` \| `"indeterminate"` | `false` | The checked state on the first render. Use when you do not need to control the state.                  |
| `onCheckedChange?` | `(checked: boolean) => void`   |         | Event handler called when the checked state changes. It runs even when `onSelect` keeps the menu open. |

The item sets `aria-checked` to `true`, `false`, or `mixed` for `"indeterminate"`.

#### Data attributes

| Data Attribute | Value                                             | Description                          |
| :------------- | :------------------------------------------------ | :----------------------------------- |
| `data-slot`    | `"dropdown-menu-checkbox-item"`                   | On the item element.                 |
| `data-state`   | `"checked"` \| `"unchecked"` \| `"indeterminate"` | On the item element.                 |
| `data-slot`    | `"dropdown-menu-checkbox-item-label"`             | On the `<span>` wrapping `children`. |

### DropdownMenu.RadioGroup

A radio group container for exclusive selection within the dropdown menu.

| Prop             | Type                      | Default | Description                                                                                        |
| :--------------- | :------------------------ | :------ | :------------------------------------------------------------------------------------------------- |
| `value?`         | `string`                  |         | The value of the selected item, for a controlled group. Must be used with `onValueChange`.         |
| `defaultValue?`  | `string`                  |         | The value of the selected item on the first render. Use when you do not need to control the state. |
| `onValueChange?` | `(value: string) => void` |         | Event handler called when the value changes.                                                       |

### DropdownMenu.Label

A label for grouping and describing sections within the dropdown menu.

| Prop     | Type      | Default | Description                                                         |
| :------- | :-------- | :------ | :------------------------------------------------------------------ |
| `inset?` | `boolean` |         | When `true`, adds left padding to align with items that have icons. |

### DropdownMenu.Group

A group container for organizing related dropdown menu items, with `role="group"`. All props of a `<div>`.

### DropdownMenu.Separator

A visual separator for dividing sections within the dropdown menu. All props from [`Separator`](/components/structure/separator).

### DropdownMenu.Shortcut

A keyboard shortcut indicator for dropdown menu items. It locks `translate="no"`, because a translated key name names the wrong key. All props from [span](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/span#attributes) except `translate`.

### DropdownMenu.Sub

A submenu container for creating nested dropdown menus. It renders no element.

| Prop            | Type                      | Default | Description                                                                                |
| :-------------- | :------------------------ | :------ | :----------------------------------------------------------------------------------------- |
| `open?`         | `boolean`                 |         | The controlled open state of the submenu. Must be used in conjunction with `onOpenChange`. |
| `onOpenChange?` | `(open: boolean) => void` |         | Event handler called when the open state of the submenu changes.                           |
| `defaultOpen?`  | `boolean`                 |         | The open state of the submenu when it is initially rendered.                               |

### DropdownMenu.SubTrigger

`children` render inside a `<span data-slot="dropdown-menu-sub-trigger-label">`. The caret is a permanent element sibling, so without the span a bare text label is never a lone child: a browser translation engine reparents that text node, and the removal React runs when the label changes shape or goes away throws. Match the part's own variant instead: `[&>[data-slot=dropdown-menu-sub-trigger-label]>svg]:size-4`. A `[&_svg]` class or a class on the icon itself loses to the item's default, which carries one more attribute selector.

| Prop     | Type      | Default | Description                                                         |
| :------- | :-------- | :------ | :------------------------------------------------------------------ |
| `inset?` | `boolean` |         | When `true`, adds left padding to align with items that have icons. |

#### Data attributes

| Data Attribute | Value                               | Description                          |
| :------------- | :---------------------------------- | :----------------------------------- |
| `data-slot`    | `"dropdown-menu-sub-trigger"`       | On the item element.                 |
| `data-slot`    | `"dropdown-menu-sub-trigger-label"` | On the `<span>` wrapping `children`. |

### DropdownMenu.SubContent

The content container for submenu items. Appears in a portal with scrolling and animations. It opens beside its `SubTrigger`, on the end side, and flips when only the other side fits.

All props of a `<div>`, plus:

| Prop                    | Type                                                            | Default   | Description                                                                                                  |
| :---------------------- | :-------------------------------------------------------------- | :-------- | :----------------------------------------------------------------------------------------------------------- |
| `loop?`                 | `boolean`                                                       | `true`    | When `true`, `ArrowDown` on the last item moves to the first, and `ArrowUp` on the first moves to the last.  |
| `align?`                | `"start" \| "end"`                                              | `"start"` | Which edge of the submenu lines up with the `SubTrigger`: the top edge (`start`) or the bottom edge (`end`). |
| `sideOffset?`           | `number`                                                        | `2`       | The distance in pixels from the `SubTrigger`.                                                                |
| `onEscapeKeyDown?`      | `(event: KeyboardEvent) => void`                                |           | Runs on `Escape`. Call `event.preventDefault()` to keep the menu open.                                       |
| `onPointerDownOutside?` | `(event: PointerDownOutsideEvent) => void`                      |           | Runs when a pointer press starts outside the submenu. Call `event.preventDefault()` to keep it open.         |
| `onFocusOutside?`       | `(event: FocusOutsideEvent) => void`                            |           | Runs when focus moves outside the submenu. Call `event.preventDefault()` to keep it open.                    |
| `onInteractOutside?`    | `(event: PointerDownOutsideEvent \| FocusOutsideEvent) => void` |           | Runs for both an outside press and an outside focus move. Call `event.preventDefault()` to keep it open.     |
