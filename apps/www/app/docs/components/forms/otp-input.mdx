# OTP Input

Accessible one-time passcode (OTP) input with paste, autofill, and IME support. Pair it with `Field` to connect its label, description, and errors in a form.

<Example name="components/forms/otp-input/overview" title="OTP Input example">

```tsx
import { Field } from "@ngrok/mantle/field";
import { OtpInput } from "@ngrok/mantle/otp-input";

<Field.Item className="w-fit" name="otp">
	<Field.Label>Verification code</Field.Label>
	<Field.Control>
		<OtpInput.Root maxLength={6}>
			<OtpInput.Group>
				<OtpInput.Slot index={0} />
				<OtpInput.Slot index={1} />
				<OtpInput.Slot index={2} />
				<OtpInput.Slot index={3} />
				<OtpInput.Slot index={4} />
				<OtpInput.Slot index={5} />
			</OtpInput.Group>
		</OtpInput.Root>
	</Field.Control>
	<Field.Description>Enter the 6-digit code we emailed you.</Field.Description>
</Field.Item>;
```

</Example>

## When to use

- Capture a short, fixed-length one-time passcode, with one box for each character: two-factor codes, email verification codes, magic-link codes, and similar flows.
- Prefer [`Input`](/components/forms/input) when the value is free-form text.
- Prefer [`PasswordInput`](/components/forms/password-input) when the value is a password or another long-lived secret.

## With TanStack Form

Use `@tanstack/react-form` with `zod` to validate the hidden OTP input while `Field.Control` handles label, name, and validation ARIA.

<Example name="components/forms/otp-input/with-tanstack-form" title="OTP Input With TanStack Form example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { Field, toErrorMessages } from "@ngrok/mantle/field";
import { OtpInput, REGEXP_ONLY_DIGITS } from "@ngrok/mantle/otp-input";
import { useForm } from "@tanstack/react-form";
import { z } from "zod";

export const formSchema = z.object({
	code: z.string().length(6, "Enter the 6-digit code."),
});
function Example() {
	const defaultValues = {
		code: "",
	};
	const form = useForm({
		defaultValues,
		validators: {
			onSubmit: formSchema,
		},
		onSubmit: ({ value }) => {
			// Handle form submission here
		},
	});

	return (
		<form
			onSubmit={(event) => {
				event.preventDefault();
				event.stopPropagation();
				void form.handleSubmit();
			}}
		>
			<form.Field name="code">
				{(field) => (
					<Field.Item name={field.name}>
						<Field.Label>Verification code</Field.Label>
						<Field.Control>
							<OtpInput.Root
								value={field.state.value}
								onBlur={field.handleBlur}
								onChange={field.handleChange}
								maxLength={6}
								pattern={REGEXP_ONLY_DIGITS}
							>
								<OtpInput.Group>
									<OtpInput.Slot index={0} />
									<OtpInput.Slot index={1} />
									<OtpInput.Slot index={2} />
									<OtpInput.Slot index={3} />
									<OtpInput.Slot index={4} />
									<OtpInput.Slot index={5} />
								</OtpInput.Group>
							</OtpInput.Root>
						</Field.Control>
						<Field.Errors messages={toErrorMessages(field.state.meta.errors)} />
					</Field.Item>
				)}
			</form.Field>
			<Button type="submit" appearance="filled" intent="neutral">
				Submit
			</Button>
		</form>
	);
}
```

</Example>

## Validation

Pass `validation="error"`, `"success"`, or `"warning"` on `OtpInput.Root` to
recolor each group's outer borders and the active focus ring with the matching
validation hue. `validation="error"` also sets `aria-invalid` on the
underlying input so assistive tech announces the failure state.

`validation` may be a literal value or a function that returns a value. Since
the prop also accepts `false`, form-library state can short-circuit validation
styling, e.g.
`validation={field.state.meta.errors.length > 0 && "error"}`.

<Example name="components/forms/otp-input/validation" title="OTP Input validation example">

```tsx
// "success" and "warning" render the same structure with a different hue.
<OtpInput.Root aria-label="Verification code" maxLength={6} validation="error">
	<OtpInput.Group>
		<OtpInput.Slot index={0} />
		<OtpInput.Slot index={1} />
		<OtpInput.Slot index={2} />
	</OtpInput.Group>
	<OtpInput.Separator />
	<OtpInput.Group>
		<OtpInput.Slot index={3} />
		<OtpInput.Slot index={4} />
		<OtpInput.Slot index={5} />
	</OtpInput.Group>
</OtpInput.Root>
```

</Example>

## Composition

Compose the parts of an `OtpInput` together to build your own:

```text showLineNumbers=false
OtpInput.Root
├── OtpInput.Group
│   └── OtpInput.Slot
├── OtpInput.Separator
└── OtpInput.Group
    └── OtpInput.Slot
```

## Polymorphism

`OtpInput.Group` and `OtpInput.Separator` accept an `asChild` prop. When `true`,
the part renders its single child instead of its default `div`, forwarding all
class names, `data-*` attributes, and the ref onto that child. Use this when you
need a different underlying element: for example, rendering the separator as a
semantic span, or wrapping a group in a styled label.

<Example name="components/forms/otp-input/polymorphism" title="OTP Input polymorphism example">

```tsx
<OtpInput.Separator asChild>
	<span aria-hidden>·</span>
</OtpInput.Separator>
```

</Example>

## Accessibility

`OtpInput` renders one native `<input>` over the slots, with `autocomplete="one-time-code"` and `inputmode="numeric"`. The browser handles typing, paste, IME, and SMS and password manager fill, as in any input, and each slot shows one character of its value. A form submits the value under the input's `name`.

The input is invisible, but it carries the value and the focus, so it needs an accessible name. Inside a `Field.Item`, `Field.Label` supplies it through the `Field.Item` id. On its own, pass `aria-label` to `OtpInput.Root`. Every example above that renders the control without a `Field.Label` does so.

## Translation

Every `OtpInput.Slot` carries [`translate="no"`](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/translate), so a browser translation engine skips the character inside it. A translated passcode character is wrong, and the reader types it back anyway.

The attribute also protects the render. Google Translate wraps each text node in a `<font>`, which detaches the node React holds. The next keystroke then makes React remove a node its parent no longer owns, and the DOM raises `NotFoundError`. Without the guard, a backspace on a translated page tears down the root.

`OtpInput.Slot` omits the `translate` prop from its type, so no call site can turn the guard off. A passcode character is never translatable, unlike [`Code`](/components/data-display/code), which also styles terms that are not code and therefore takes the override.

[Browser translation](/browser-translation) covers what an engine does to a React DOM, and the rule your own components need.

## API Reference

### OtpInput.Root

The root of the OTP input. Renders the native input that takes keystrokes,
paste, and autofill, and passes each `OtpInput.Slot` its character and active
state.

All props from [input](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input#attributes), plus:

| Prop                           | Type                             | Default            | Description                                                                                                            |
| ------------------------------ | -------------------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------- |
| `maxLength`                    | `number`                         |                    | The total number of character slots. Required.                                                                         |
| `value?`                       | `string`                         |                    | Controlled value.                                                                                                      |
| `defaultValue?`                | `string`                         |                    | Uncontrolled initial value.                                                                                            |
| `onChange?`                    | `(value: string) => void`        |                    | Fired when the value changes.                                                                                          |
| `onComplete?`                  | `(value: string) => void`        |                    | Fired when the value grows to `maxLength` characters, by typing, paste, or a parent.                                   |
| `pattern?`                     | `string`                         |                    | Regex source restricting accepted characters (e.g. `REGEXP_ONLY_DIGITS`).                                              |
| `textAlign?`                   | `"left" \| "center" \| "right"`  | `"left"`           | Caret alignment within the hidden input.                                                                               |
| `containerClassName?`          | `string`                         |                    | Class applied to the slot container element.                                                                           |
| `pasteTransformer?`            | `(pasted: string) => string`     |                    | Transform pasted text before it is consumed.                                                                           |
| `pushPasswordManagerStrategy?` | `"increase-width" \| "none"`     | `"increase-width"` | On focus, widen the input past the last slot when there is room, so a password manager badge sits beside it.           |
| `noScriptCSSFallback?`         | `string \| null`                 |                    | CSS for the input when JavaScript is off. It selects the input with `[data-input-otp]`. `null` turns the fallback off. |
| `validation?`                  | `Validation \| () => Validation` |                    | Validation state. `"error"` also sets `aria-invalid` on the input.                                                     |

| Data Attribute                     | Value                                         | Description                                                                                                   |
| ---------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| `data-slot`                        | `"otp-input"`                                 | On the `<input>`.                                                                                             |
| `data-otp-state`                   | `"idle"` \| `"caret"` \| `"range"` \| `"all"` | On the `group/otp` wrapper of the slots. How many slots the selection covers: none, one, some, or all.        |
| `data-validation`                  | `"error"` \| `"success"` \| `"warning"`       | On the `group/otp` wrapper of the slots. The resolved `validation`. Omitted when unset.                       |
| `data-input-otp-container`         | `"true"`                                      | On the box that holds the slots and the input. A page style can select it.                                    |
| `data-input-otp`                   | `"true"`                                      | On the `<input>`. A `noScriptCSSFallback` or a page style can select it.                                      |
| `data-input-otp-mss`               | a number                                      | On the `<input>`. The selection start. Omitted before the input has a selection.                              |
| `data-input-otp-mse`               | a number                                      | On the `<input>`. The selection end. Omitted before the input has a selection.                                |
| `data-input-otp-placeholder-shown` | `"true"`                                      | On the `<input>` while it is empty. Its value is `"true"`, not presence, so existing page styles still match. |
| `data-lpignore`                    | `"true"`                                      | On the `<input>`. Keeps the LastPass badge off; LastPass does not fill one-time codes.                        |

### OtpInput.Group

Groups one or more `OtpInput.Slot` parts into a visually-connected segment with shared rounded corners and joined borders.

All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes), plus:

| Prop       | Type      | Default | Description                                       |
| ---------- | --------- | ------- | ------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Render as a different element by passing a child. |

### OtpInput.Slot

A single character slot. Must be rendered inside an `OtpInput.Root`. Reads its character, active state, and fake caret position from the root via context. Always renders `translate="no"`. See [Translation](#translation).

All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes) except `translate`, plus:

| Prop    | Type     | Default | Description                                                    |
| ------- | -------- | ------- | -------------------------------------------------------------- |
| `index` | `number` |         | Zero-based index of the slot. Required. Must be `< maxLength`. |

| Data Attribute     | Value               | Description                                               |
| ------------------ | ------------------- | --------------------------------------------------------- |
| `data-slot`        | `"otp-input-slot"`  | The slot.                                                 |
| `data-highlighted` | present when active | Presence-only. The caret or the selection is on the slot. |

### OtpInput.Separator

A visual separator between two `OtpInput.Group` segments. Renders a minus icon by default; pass `children` to override.

All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes), plus:

| Prop        | Type      | Default | Description                                                                                          |
| ----------- | --------- | ------- | ---------------------------------------------------------------------------------------------------- |
| `asChild?`  | `boolean` | `false` | Render as a different element by passing a child.                                                    |
| `semantic?` | `boolean` | `false` | If `true`, renders with `role="separator"`. Otherwise the separator is decorative and `aria-hidden`. |

### Pattern helpers

Pass one to `pattern`:

| Export                         | Pattern          |
| ------------------------------ | ---------------- |
| `REGEXP_ONLY_DIGITS`           | `^\d+$`          |
| `REGEXP_ONLY_CHARS`            | `^[a-zA-Z]+$`    |
| `REGEXP_ONLY_DIGITS_AND_CHARS` | `^[a-zA-Z0-9]+$` |
