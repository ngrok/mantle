# Segmented Control

A row of segments that switches between a few short options, like a view or an environment. A raised thumb slides to the checked segment.

<Example name="components/forms/segmented-control/overview" title="Segmented Control example">

```tsx
import { SegmentedControl } from "@ngrok/mantle/segmented-control";

<SegmentedControl.Root aria-label="Environment" defaultValue="production">
	<SegmentedControl.Item value="development">Dev</SegmentedControl.Item>
	<SegmentedControl.Item value="staging" disabled>
		Staging
	</SegmentedControl.Item>
	<SegmentedControl.Item value="production">Prod</SegmentedControl.Item>
</SegmentedControl.Root>;
```

</Example>

## When to use

- Switch between a few short options in one compact, inline row, such as a view, an environment, or a filter.
- Prefer [`RadioGroup`](/components/forms/radio-group) for a form field whose options need a description, or stack in a column.
- Prefer [`Tabs`](/components/navigation/tabs) when each option shows its own panel of content.
- Prefer [`Select`](/components/forms/select) when the set is long, or the row has little space.

## Controlled

Pass `value` and `onValueChange` to keep the checked segment in your own state. The control reports the new value on a click, a key, and a drag.

<Example name="components/forms/segmented-control/controlled" title="Segmented Control controlled example">

```tsx
import { SegmentedControl } from "@ngrok/mantle/segmented-control";
import { useState } from "react";

function ControlledExample() {
	const [view, setView] = useState("list");

	return (
		<div className="flex flex-col items-center gap-3">
			<SegmentedControl.Root aria-label="View" value={view} onValueChange={setView}>
				<SegmentedControl.Item value="list">List</SegmentedControl.Item>
				<SegmentedControl.Item value="board">Board</SegmentedControl.Item>
				<SegmentedControl.Item value="calendar">Calendar</SegmentedControl.Item>
			</SegmentedControl.Root>
			<p className="text-muted text-sm">Current view: {view}</p>
		</div>
	);
}
```

</Example>

## Icon segments

A segment can hold only an icon. Give each one its name in `sr-only` text, so a screen reader announces it.

<Example name="components/forms/segmented-control/icon-segments" title="Segmented Control icon segments example">

```tsx
import { SegmentedControl } from "@ngrok/mantle/segmented-control";
import { ListIcon } from "@phosphor-icons/react/List";
import { SquaresFourIcon } from "@phosphor-icons/react/SquaresFour";

<SegmentedControl.Root aria-label="Layout" defaultValue="list" className="w-fit">
	<SegmentedControl.Item value="list">
		<ListIcon aria-hidden className="size-5" />
		<span className="sr-only">List</span>
	</SegmentedControl.Item>
	<SegmentedControl.Item value="grid">
		<SquaresFourIcon aria-hidden className="size-5" />
		<span className="sr-only">Grid</span>
	</SegmentedControl.Item>
</SegmentedControl.Root>;
```

## Size

Set `size` on `SegmentedControl.Root` to set the height of the whole control, default `md`. The scale is the one [Button](/components/actions/button), [IconButton](/components/actions/icon-button), and [SplitButton](/components/actions/split-button) use: `xs`, `sm`, `md`, `lg`, and `xl`. A control lines up with buttons of the same size in a toolbar. A `Button` with `appearance="link"` has no box, so it has no height to match. The items do not accept `size`, so the items of one control always share one height.

<Example name="components/forms/segmented-control/size" title="Segmented Control size example">

## With TanStack Form

Use `@tanstack/react-form` with `zod` to keep the control controlled in a form. Pass the field's `name`, `value`, and `handleChange`. Use `Field.Set` and `Field.Legend` to name the group and show its errors.

<Example name="components/forms/segmented-control/with-tanstack-form" title="Segmented Control With TanStack Form example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { Field, toErrorMessages } from "@ngrok/mantle/field";
import { SegmentedControl } from "@ngrok/mantle/segmented-control";
import { useForm } from "@tanstack/react-form";
import { z } from "zod";

export const formSchema = z.object({
	region: z.string().min(1, "Choose a region."),
});

function TanStackFormExample() {
	const form = useForm({
		defaultValues: { region: "" },
		validators: {
			onSubmit: formSchema,
		},
		onSubmit: ({ value }) => {
			// Handle form submission here
		},
	});

	return (
		<form
			onSubmit={(event) => {
				event.preventDefault();
				event.stopPropagation();
				void form.handleSubmit();
			}}
		>
			<form.Field name="region">
				{(field) => (
					<Field.Set>
						<Field.Legend>Region</Field.Legend>
						<SegmentedControl.Root
							name={field.name}
							value={field.state.value}
							onValueChange={field.handleChange}
						>
							<SegmentedControl.Item value="us">US</SegmentedControl.Item>
							<SegmentedControl.Item value="eu">EU</SegmentedControl.Item>
							<SegmentedControl.Item value="ap">AP</SegmentedControl.Item>
						</SegmentedControl.Root>
						<Field.Errors messages={toErrorMessages(field.state.meta.errors)} />
					</Field.Set>
				)}
			</form.Field>
			<Button type="submit" appearance="filled" intent="neutral">
				Submit
			</Button>
		</form>
	);
}
```

</Example>

## Radio semantics

`SegmentedControl` is a radio group of native radios. It shares its primitive with [`RadioGroup`](/components/forms/radio-group), so it has the same contract: `role="radiogroup"`, one tab stop, arrow keys that move the checked segment, and form submission when it has a `name`. Each segment is a `<div>` with an invisible `<input type="radio">` in it, so style a segment's state with `has-[>input:checked]:`, `has-[>input:disabled]:`, and `has-[>input:focus-visible]:`.

To change the value, click a segment, use the arrow keys, or drag the thumb with a mouse or a finger.

## Dragging the thumb

A sideways drag on the checked segment moves the thumb with the pointer. On release, the thumb slides to the nearest enabled segment, and that segment becomes checked. A flick carries the thumb further. Past either end, the thumb meets resistance and stays inside the track. A drag that goes up or down more than sideways does not start, so the page still scrolls on a touch screen.

The thumb slides on every change: a click, a key, a drag, or a new `value`. With reduced motion, it moves at once.

## API Reference

### SegmentedControl.Root

The row of segments. It renders the radio group itself, so use it in place of `RadioGroup.Root`, never inside one.

The same props as [`RadioGroup.Root`](/components/forms/radio-group#radiogrouproot), including:

| Prop             | Type                      | Default | Description                                                 |
| :--------------- | :------------------------ | :------ | :---------------------------------------------------------- |
| `value?`         | `string`                  |         | The controlled value of the checked segment.                |
| `defaultValue?`  | `string`                  |         | The value checked at first, when uncontrolled.              |
| `onValueChange?` | `(value: string) => void` |         | Called with the new value when the checked segment changes. |
| `disabled?`      | `boolean`                 | `false` | When `true`, prevents interaction with every segment.       |
| `name?`          | `string`                  |         | The form field name. With a name, a form submits the value. |
| `required?`      | `boolean`                 | `false` | When `true`, a form submits only when a segment is checked. |
| `form?`          | `string`                  |         | The `id` of the form the radios belong to.                  |
| `aria-label?`    | `string`                  |         | The name of the control. Set it, or set `aria-labelledby`.  |

It also takes:

| Prop    | Type                                           | Default | Description                                                                 |
| :------ | :--------------------------------------------- | :------ | :-------------------------------------------------------------------------- |
| `size?` | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"` | `"md"`  | The height of the control: 24px, 28px, 36px, 40px, or 48px, as on `Button`. |

| Data Attribute  | Value                                          | Description                                   |
| :-------------- | :--------------------------------------------- | :-------------------------------------------- |
| `data-slot`     | `"segmented-control"`                          | The control.                                  |
| `data-size`     | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"` | The `size` prop.                              |
| `data-dragging` | present during a drag                          | The thumb follows the pointer. Presence-only. |

### SegmentedControl.Item

One segment. It grows to share the row and keeps its label on one line, so keep labels to one or two words. Inside `Field.Control`, the segment picks up `aria-invalid`, `aria-errormessage`, and `aria-describedby`.

| Prop        | Type      | Default | Description                                                 |
| :---------- | :-------- | :------ | :---------------------------------------------------------- |
| `value`     | `string`  |         | The value the control reports when this segment is checked. |
| `disabled?` | `boolean` |         | When `true`, the segment cannot be checked.                 |

| Data Attribute    | Value                            | Description                                                |
| :---------------- | :------------------------------- | :--------------------------------------------------------- |
| `data-slot`       | `"segmented-control-item"`       | The segment: a `<div>` with its radio.                     |
| `data-slot`       | `"segmented-control-item-label"` | The `display: contents` wrapper of the segment's children. |
| `data-thumb-over` | present during a drag            | The thumb is over this segment. Presence-only.             |
