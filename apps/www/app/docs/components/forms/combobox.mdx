# Combobox

A text input with autocomplete: the user types to filter a list of suggested values and picks one, with full keyboard support. Wrap `Combobox.Input` in `Field.Control` to connect it to the label, description, and errors of a form field.

<Example name="components/forms/combobox/overview" title="Combobox example">

```tsx
import { Combobox } from "@ngrok/mantle/combobox";
import { Field } from "@ngrok/mantle/field";

<Field.Item name="subdomain">
	<Field.Label>Subdomain</Field.Label>
	<Combobox.Root>
		<Field.Control>
			<Combobox.Input placeholder="Choose an ngrok subdomain..." />
		</Field.Control>
		<Combobox.Content>
			<Combobox.Group>
				<Combobox.GroupLabel>Available domains</Combobox.GroupLabel>
				<Combobox.Item value="https://${random}.ngrok.app">
					<Combobox.ItemValue />
				</Combobox.Item>
				<Combobox.Item value="https://${random}.ngrok.dev">
					<Combobox.ItemValue />
				</Combobox.Item>
				<Combobox.Item value="https://${random}.ngrok.io">
					<Combobox.ItemValue />
				</Combobox.Item>
			</Combobox.Group>
		</Combobox.Content>
	</Combobox.Root>
	<Field.Description>Start typing to filter available domains.</Field.Description>
</Field.Item>;
```

</Example>

## When to use

- Pick one value from a long list, with a text field that filters the options as the user types.
- Search async or server-side data for one value.
- Prefer [`Select`](/components/forms/select) when the list is short and needs no filter.
- Prefer [`MultiSelect`](/components/forms/multi-select) when the user picks several values, shown as tags.
- Prefer [`Command`](/components/navigation/command) when the list runs actions or goes to pages, in a palette.
- Prefer [`Query`](/components/forms/query) when the field filters a list with free text and `key:value` qualifiers.

## Layering and z-index

`Combobox.Content` is a `popover="manual"` element in the top layer, so it paints above the page and every overlay. It portals into the overlay or float that holds it, such as an open `Dialog` or `Popover.Content`, else into `document.body`. In a browser with no popover API, it is a fixed box at Tailwind `z-50`. It opens below the input, or above it when the space below is too small.

`Combobox` does not render a backdrop. Modal layers such as `Dialog`, `Sheet`, and `AlertDialog` do render backdrops, so stacking those layers compounds the dim and blur effect on the layers underneath.

## Examples

### With TanStack Form

Use `@tanstack/react-form` with `zod` to keep the picked value controlled. Each item's `value` is the region ID the form stores, and the input shows the item's text. Wrap `Combobox.Input` in `Field.Control` so label, name, and validation ARIA are applied to the focusable input.

<Example name="components/forms/combobox/with-tanstack-form" title="Combobox With TanStack Form example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { Combobox } from "@ngrok/mantle/combobox";
import { Field, toErrorMessages } from "@ngrok/mantle/field";
import { useForm } from "@tanstack/react-form";
import { z } from "zod";

export const formSchema = z.object({
	region: z.string().min(1, "Choose a region."),
});
function Example() {
	const defaultValues = {
		region: "",
	};
	const form = useForm({
		defaultValues,
		validators: {
			onSubmit: formSchema,
		},
		onSubmit: ({ value }) => {
			// Handle form submission here
		},
	});

	return (
		<form
			onSubmit={(event) => {
				event.preventDefault();
				event.stopPropagation();
				void form.handleSubmit();
			}}
		>
			<form.Field name="region">
				{(field) => (
					<Field.Item name={field.name}>
						<Field.Label>Region</Field.Label>
						<Combobox.Root
							value={field.state.value}
							onValueChange={(value) => {
								field.handleChange(value);
							}}
						>
							<Field.Control>
								<Combobox.Input onBlur={field.handleBlur} placeholder="Choose a region..." />
							</Field.Control>
							<Combobox.Content>
								<Combobox.Item value="us-east-1">US East</Combobox.Item>
								<Combobox.Item value="us-west-2">US West</Combobox.Item>
								<Combobox.Item value="eu-west-1">EU West</Combobox.Item>
							</Combobox.Content>
						</Combobox.Root>
						<Field.Errors messages={toErrorMessages(field.state.meta.errors)} />
					</Field.Item>
				)}
			</form.Field>
			<Button type="submit" appearance="filled" intent="neutral">
				Submit
			</Button>
		</form>
	);
}
```

</Example>

## Composition

Compose the parts of a `Combobox` together to build your own:

```text showLineNumbers=false
Combobox.Root
├── Combobox.Input
└── Combobox.Content
    ├── Combobox.Group
    │   ├── Combobox.GroupLabel
    │   └── Combobox.Item
    │       └── Combobox.ItemValue
    ├── Combobox.Separator
    └── Combobox.ContentFooter
```

## With a footer

Put a switch, a "Load more" button, or a link in `Combobox.ContentFooter`. It renders at the bottom of the popover, after the listbox and not in it, because a listbox holds only options and groups. Tab from the input moves to the footer's first control and keeps the list open. Shift+Tab from that control returns to the input. Escape closes the list and returns focus to the input. Tab from the last control moves to the control after the field and closes the list.

<Example name="components/forms/combobox/with-a-footer" title="Combobox with a footer example">

```tsx
import { Button } from "@ngrok/mantle/button";
import { Combobox } from "@ngrok/mantle/combobox";
import { Field } from "@ngrok/mantle/field";
import { Switch } from "@ngrok/mantle/switch";
import { useState } from "react";

const releases = ["v1.4.0", "v1.3.2", "v1.3.1", "v1.3.0", "v1.2.0", "v1.1.0"];

function Example() {
	const [showAll, setShowAll] = useState(false);
	const [count, setCount] = useState(3);
	const shown = releases.slice(0, showAll ? releases.length : count);
	return (
		<Field.Item name="release">
			<Field.Label>Release</Field.Label>
			<Combobox.Root>
				<Field.Control>
					<Combobox.Input placeholder="Search releases..." />
				</Field.Control>
				<Combobox.Content>
					{shown.map((release) => (
						<Combobox.Item key={release} value={release} />
					))}
					<Combobox.ContentFooter className="flex items-center justify-between gap-2 p-2">
						<div className="flex items-center gap-2 text-sm">
							<Switch id="show-all-releases" checked={showAll} onCheckedChange={setShowAll} />
							<label htmlFor="show-all-releases">Show all releases</label>
						</div>
						<Button
							type="button"
							appearance="ghost"
							intent="accent"
							disabled={showAll || count >= releases.length}
							onClick={() => setCount((current) => current + 3)}
						>
							Load more
						</Button>
					</Combobox.ContentFooter>
				</Combobox.Content>
			</Combobox.Root>
		</Field.Item>
	);
}
```

</Example>

## Polymorphism

`Combobox.Content`, `Combobox.Item`, `Combobox.Group`, and `Combobox.GroupLabel` support `asChild` to render as a different element or your own component while keeping the combobox behavior and styling.

`Combobox.Item` also takes a function child, `(props, { highlighted }) => element`, for a row that renders different content while highlighted, such as a preview. Only a row that uses one re-renders when the highlight moves. To only restyle the highlighted row, use the `data-highlighted:` variant, or `in-data-highlighted:` from a child, which needs no JavaScript. Anything you write after `{...props}` wins, so join a class with `cx(props.className, "…")`, and set `id` on the item, not on your element.

<Example name="components/forms/combobox/polymorphism" title="Combobox polymorphism example">

```tsx
import { Combobox } from "@ngrok/mantle/combobox";

<Combobox.Root>
	<Combobox.Input placeholder="Search links..." />
	<Combobox.Content>
		<Combobox.Item value="Dashboard" asChild>
			<a href="#dashboard">Dashboard</a>
		</Combobox.Item>
		<Combobox.Item value="Settings" asChild>
			<a href="#settings">Settings</a>
		</Combobox.Item>
	</Combobox.Content>
</Combobox.Root>;
```

</Example>

## Accessibility

`Combobox` follows the [WAI-ARIA Combobox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/) with list autocomplete. DOM focus stays on the input, and `aria-activedescendant` names the highlighted option. `Combobox.ContentFooter` renders outside the listbox, so its controls are ordinary buttons and switches in the Tab order, and the listbox holds only options. Inside a field, `Field.Control` puts the generated `id`, `name`, `aria-describedby`, `aria-errormessage`, and `aria-invalid` on the focusable input.

## API Reference

### Combobox.Root

The outermost part of a combobox. It holds the query text, the open state, and the selection.

`Combobox.Content` is a `popover="manual"` element in the top layer, so it paints above the page and every overlay. It portals into the overlay or float that holds it, such as an open `Dialog` or `Popover.Content`, else into `document.body`. In a browser with no popover API, it is a fixed box at Tailwind `z-50`. It opens below the input, or above it when the space below is too small.

| Prop                  | Type                           | Default | Description                                                                               |
| :-------------------- | :----------------------------- | :------ | :---------------------------------------------------------------------------------------- |
| `value?`              | `string`                       |         | The controlled value of the picked item. Pair with `onValueChange`.                       |
| `defaultValue?`       | `string`                       |         | The value of the picked item on first render.                                             |
| `onValueChange?`      | `(value: string) => void`      |         | Called when the user picks an item.                                                       |
| `inputValue?`         | `string`                       |         | The controlled text of the input. Pair with `onInputValueChange`.                         |
| `defaultInputValue?`  | `string`                       | `""`    | The text of the input on first render.                                                    |
| `onInputValueChange?` | `(inputValue: string) => void` |         | Called when the text of the input changes.                                                |
| `open?`               | `boolean`                      |         | The controlled open state. Pair with `onOpenChange`.                                      |
| `defaultOpen?`        | `boolean`                      | `false` | Whether the list is open on first render.                                                 |
| `onOpenChange?`       | `(open: boolean) => void`      |         | Called when the open state changes.                                                       |
| `name?`               | `string`                       |         | The name the picked value submits under. The text in `Combobox.Input` does not submit.    |
| `form?`               | `string`                       |         | The `id` of the form the picked value submits with, when it is not an ancestor.           |
| `required?`           | `boolean`                      |         | Whether a pick is required before the form submits.                                       |
| `disabled?`           | `boolean`                      |         | Whether the combobox is disabled. The input takes no input, and the pick does not submit. |

A form reset returns the pick to `defaultValue` and the text to `defaultInputValue`. With a `name` on `Combobox.Root`, a `name` on `Combobox.Input` is ignored, so only the pick submits. The picked item carries `data-selected`. `aria-selected` follows the highlight, as the APG combobox pattern asks.

### Combobox.Input

Renders a combobox input element for filtering a list of items.

All props of an `<input>` except `value`, `defaultValue`, and `autoComplete`, plus:

| Prop          | Type                                                                                               | Default    | Description                                                                                                                          |
| :------------ | :------------------------------------------------------------------------------------------------- | :--------- | :----------------------------------------------------------------------------------------------------------------------------------- |
| `autoSelect?` | `boolean \| "always"`                                                                              | `"always"` | Whether the first item gets the highlight as the text changes, so Enter picks it. `"always"` also highlights it when the list opens. |
| `validation?` | `"error" \| "success" \| "warning" \| false \| (() => "error" \| "success" \| "warning" \| false)` |            | Validation state that changes the border and outline.                                                                                |

### Combobox.Content

Renders a popover that contains combobox content, e.g. items, groups, and separators.

`Combobox.Content` is a `popover="manual"` element in the top layer, so it paints above the page and every overlay. It portals into the overlay or float that holds it, such as an open `Dialog` or `Popover.Content`, else into `document.body`. In a browser with no popover API, it is a fixed box at Tailwind `z-50`. It opens below the input, or above it when the space below is too small.

`Combobox.Content` is the `role="listbox"` element, and it scrolls. It sits in a popover that also holds the `Combobox.ContentFooter`, after the listbox. All props of a `<div>`, plus:

| Prop         | Type      | Default | Description                                                           |
| :----------- | :-------- | :------ | :-------------------------------------------------------------------- |
| `asChild?`   | `boolean` | `false` | Compose onto an alternative element type or your own React component. |
| `sameWidth?` | `boolean` | `true`  | Whether the popover should be the same width as the input.            |

### Combobox.Item

Renders a combobox item inside a `Combobox.Content` component.

All props of a `<div>`, plus:

| Prop        | Type                                                      | Default | Description                                                                                                                                                     |
| :---------- | :-------------------------------------------------------- | :------ | :-------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `asChild?`  | `boolean`                                                 | `false` | Compose onto an alternative element type or your own React component.                                                                                           |
| `children?` | `ReactNode` \| `(props, { highlighted }) => ReactElement` | `value` | The item's content. A function renders the item as the element it returns, with the item's props and whether it is highlighted. Spread `props` on that element. |
| `disabled?` | `boolean`                                                 |         | Whether the item is inert.                                                                                                                                      |
| `value?`    | `string`                                                  |         | The value that picking the item sets on `Combobox.Root`, such as an ID. An item with no value is static text that the keyboard skips.                           |

#### The text a pick writes

A pick writes the text that the item's children show into the input, without their `aria-hidden` parts, such as a decorative icon or avatar. A preset `value` or `defaultValue`, and a form reset, write it too. `value` stays the picked value, so an item can pick an ID and show a name:

```tsx
<Combobox.Item value="usr_7f">
	<Avatar aria-hidden="true" />
	Grace Hopper
</Combobox.Item>
```

- Filter on that text, because the input holds it after a pick.
- A preset value reads the elements you wrote. A component with no `children` prop, such as `Combobox.ItemValue` or an icon, adds no text there. An item with no text, a function child, an item that a component of your own renders, and an item that is not loaded yet show `value`.
- When the text still reads wrong, such as an email you show but do not want in the input, control `inputValue` and `onInputValueChange` and write the text yourself.
- The input stays one line. Long text ends with an ellipsis.

### Combobox.ItemValue

Highlights the match between the current `Combobox.Input` value and parent `Combobox.Item` value. Should only be used as a child of `Combobox.Item`.

All props of a `<span>` except `children`, plus:

| Prop         | Type     | Default                             | Description                  |
| :----------- | :------- | :---------------------------------- | :--------------------------- |
| `value?`     | `string` | the closest `Combobox.Item`'s value | The text to split.           |
| `userValue?` | `string` | the text of `Combobox.Input`        | The text to find in `value`. |

### Combobox.Group

Renders a group for `Combobox.Item` elements. Optionally, compose a `Combobox.GroupLabel` as a child to label the group.

All props of a `<div>`, plus:

| Prop       | Type      | Default | Description                                                           |
| :--------- | :-------- | :------ | :-------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Compose onto an alternative element type or your own React component. |

### Combobox.GroupLabel

Renders a label in a combobox group. Should be wrapped with `Combobox.Group` so the `aria-labelledby` is correctly set on the group element.

All props of a `<div>`, plus:

| Prop       | Type      | Default | Description                                                           |
| :--------- | :-------- | :------ | :-------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Compose onto an alternative element type or your own React component. |

### Combobox.Separator

Renders a separator between `Combobox.Item`s or `Combobox.Group`s.

All props from [Separator](/components/structure/separator).

### Combobox.ContentFooter

Renders a footer at the bottom of the open `Combobox.Content`, after the listbox and not in it, for controls such as a switch or a "Load more" button. Tab from the input moves to its first control, and the list stays open.

All props of a `<div>`.

**Data attributes:**

| Data Attribute | Value                       | Description                                                                            |
| -------------- | --------------------------- | -------------------------------------------------------------------------------------- |
| `data-slot`    | `"combobox-content-footer"` | On the footer.                                                                         |
| `data-slot`    | `"combobox-popup"`          | On the popover box that holds the listbox and the footer. It also carries `data-side`. |
