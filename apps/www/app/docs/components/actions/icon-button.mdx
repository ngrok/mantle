# Icon Button

Initiates an action, such as completing a task or submitting information. Renders one icon and nothing else, with a required `label` prop that carries the accessible name.

Every `IconButton` states what it means: `appearance` (visual weight) and `intent` (tone) are **required**; there are no implicit defaults. `intent` takes `"neutral"` alone: an icon carries no text to name the action a tone colors, so `IconButton` draws no accent or danger tone.

## Appearance

`IconButton` draws all three of [`Button`](/components/actions/button)'s box appearances, and each one matches its `Button` twin. `link` stays off the union — an icon-only link has no text to read as a link. An icon button sits beside a button with no color or weight seam.

	<IconButton

</Example>


## Type

Like [`Button`](/components/actions/button#type), `IconButton` defaults to **`type="button"`** rather than the native `submit`, so it never accidentally submits a surrounding `<form>`. Opt in with `type="submit"` (or `type="reset"`) when the button should submit or reset a form. When `asChild` is used, `type` has no effect and is not forwarded to the child.

## isLoading

`isLoading` determines whether the icon button is in a loading state, default `false`. Setting `isLoading` replaces the icon with a spinner. It also disables user interaction with the button and sets `aria-disabled`.

## Polymorphism

To render _something else_ as an `IconButton`, use the `asChild` prop to compose. This is useful when you want to splat the `IconButton` styling onto a `react-router` `Link`. When you use `asChild`, the `IconButton` does **NOT** pass its `type` prop to the child component.

<Example>
	<IconButton
		appearance="outlined"
		intent="neutral"
		asChild
		label="prestige worldwide"
		icon={<GlobeIcon />}
	>
		<Link to={href("/base/colors")} />
	</IconButton>
</Example>

```tsx
import { IconButton } from "@ngrok/mantle/button";
import { GlobeIcon } from "@phosphor-icons/react/Globe";
import { Link, href } from "react-router";

<IconButton
	appearance="outlined"
	intent="neutral"
	asChild
	label="prestige worldwide"
	icon={<GlobeIcon />}
>
	<Link to={href("/base/colors")} />
</IconButton>;
```

## API Reference

The `IconButton` accepts the following props in addition to the [standard HTML button attributes](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/button).

| Prop         | Type                                           | Default    | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------ | ---------------------------------------------- | ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `appearance` | `"filled"` \| `"ghost"` \| `"outlined"`        |            | The visual style of the `IconButton`. **Required** — there is no default, so every call site states the visual weight it means. Matches `Button`'s union without `"link"`.                                                                                                                                                                                                                                                                                                                                        |
| `asChild`    | `boolean`                                      | `false`    | Use the `asChild` prop to compose the `IconButton` styling and functionality onto alternative element types or your own React components.                                                                                                                                                                                                                                                                                                                                                                         |
| `icon`       | `ReactNode`                                    |            | The icon to render inside the button. When `isLoading` is `true`, the icon is automatically replaced with a spinner.                                                                                                                                                                                                                                                                                                                                                                                              |
| `intent`     | `"neutral"`                                    |            | The tone of the `IconButton` — the purpose its color communicates to the user. Narrower than `Button`'s: `"neutral"` is the only tone `IconButton` draws, so the accent and danger tones are a type error here. Still **required**, so a call site reads the same on both components.                                                                                                                                                                                                                             |
| `isLoading`  | `boolean`                                      | `false`    | Determines whether the icon button is in a loading state. Setting `isLoading` replaces the icon with a spinner. It also disables user interaction with the button and sets `aria-disabled`.                                                                                                                                                                                                                                                                                                                       |
| `label`      | `string`                                       |            | The accessible name for the button, rendered as its `aria-label` (like the `alt` text on an `<img>`). Passing `aria-label` directly is a compile error, so this prop is the only way to name the button. Name the action, not the icon: `"Delete API key"`, not `"Trash"` or `"Trash icon"`. Keep it short (a voice-control user speaks the label to click the button) and specific (`"Delete"` alone cannot tell two delete buttons apart), and never include the word "button" (the role already announces it). |
| `size`       | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"` | `"md"`     | The size of the `IconButton`, controlling its box size. Shared scale with `Button` — the same size name renders the same box height. Only the box scales; the icon glyph stays the same size.                                                                                                                                                                                                                                                                                                                     |
| `type`       | `"button"` \| `"reset"` \| `"submit"`          | `"button"` | The behavior of the `IconButton` when activated. Defaults to `"button"`, so an `IconButton` inside a `<form>` will **not** submit it — pass `type="submit"` to submit the form. When `asChild` is used, `type` has no effect and is not forwarded to the child.                                                                                                                                                                                                                                                   |

The `IconButton` also exposes the following CSS variables as part of its API.

| CSS Variable                  | Default    | Description                                                                                                                                                     |
| ----------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--icon-button-border-radius` | `0.375rem` | The border radius of the `IconButton`. Wrappers can set it to slot icon buttons into their chrome — `ButtonGroup`'s panel appearance tightens it to `0.125rem`. |
