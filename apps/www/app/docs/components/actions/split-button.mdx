# Split Button

A button group that pairs a one-click default action with a dropdown menu of related alternatives.

<Example name="components/actions/split-button/overview" title="Split Button example">

```tsx
import { CopyIcon, FileTextIcon } from "@phosphor-icons/react";
import { Icon } from "@ngrok/mantle/icon";
import { SplitButton } from "@ngrok/mantle/split-button";

<SplitButton.Root>
	<SplitButton.PrimaryAction icon={<CopyIcon />}>Copy page</SplitButton.PrimaryAction>
	<SplitButton.MenuTrigger label="Open actions menu" />
	<SplitButton.MenuContent>
		<SplitButton.MenuItem>
			<Icon svg={<CopyIcon />} />
			Copy page
		</SplitButton.MenuItem>
		<SplitButton.MenuItem>
			<Icon svg={<FileTextIcon />} />
			View as Markdown
		</SplitButton.MenuItem>
	</SplitButton.MenuContent>
</SplitButton.Root>;
```

</Example>

## When to use

- Run the action users usually want on one click, and offer the related alternatives they sometimes need in an attached menu.
- Prefer [`Button`](/components/actions/button) for one action with no alternatives.
- Prefer [`DropdownMenu`](/components/overlays/dropdown-menu) for a button that only opens a menu and runs no default action.

## Composition

Compose the parts of a `SplitButton` together to build your own:

```text showLineNumbers=false
SplitButton.Root
├── SplitButton.PrimaryAction
├── SplitButton.MenuTrigger
└── SplitButton.MenuContent
    └── SplitButton.MenuItem
```

## Size

Set the `size` prop on `SplitButton.Root` to control the height of the whole composite, default `md`. The size applies to both the primary action and the menu trigger so the two halves always share one height; the parts themselves do not accept a `size` prop. The scale is shared with [Button](/components/actions/button) and [IconButton](/components/actions/icon-button).

<Example name="components/actions/split-button/size" title="Split Button size example">

```tsx
import { PlusIcon } from "@phosphor-icons/react";
import { SplitButton } from "@ngrok/mantle/split-button";

<SplitButton.Root size="sm">
	<SplitButton.PrimaryAction icon={<PlusIcon />}>New endpoint</SplitButton.PrimaryAction>
	<SplitButton.MenuTrigger label="Open create options" />
	<SplitButton.MenuContent>
		<SplitButton.MenuItem>New domain</SplitButton.MenuItem>
	</SplitButton.MenuContent>
</SplitButton.Root>;
```

</Example>

## Menu width

The menu is at least as wide as the whole split button: the primary action and the menu trigger together. When an item is wider, the menu grows to fit it and reaches past the start edge of the split button. The menu keeps an 8rem minimum and is never wider than the viewport less 8px on each side.

To size the menu another way, set `width` on `SplitButton.MenuContent`: `"trigger"` matches the menu trigger, and `"content"` takes the width of the widest item. Both keep the 8rem minimum and align against the menu trigger, not the whole split button.

<Example name="components/actions/split-button/menu-width" title="Split Button menu width example">

```tsx
import { RocketLaunchIcon } from "@phosphor-icons/react";
import { SplitButton } from "@ngrok/mantle/split-button";

<SplitButton.Root>
	<SplitButton.PrimaryAction icon={<RocketLaunchIcon />}>Deploy</SplitButton.PrimaryAction>
	<SplitButton.MenuTrigger label="Open deploy options" />
	<SplitButton.MenuContent>
		<SplitButton.MenuItem>Deploy to staging</SplitButton.MenuItem>
		<SplitButton.MenuItem>Deploy to every production region</SplitButton.MenuItem>
	</SplitButton.MenuContent>
</SplitButton.Root>;
```

</Example>

## Polymorphism

To render _something else_ as a `SplitButton.MenuItem`, use the `asChild` prop to compose. This is useful for rendering links as menu items.

<Example name="components/actions/split-button/polymorphism" title="Split Button polymorphism example">

```tsx
import { DownloadIcon, FileTextIcon } from "@phosphor-icons/react";
import { Icon } from "@ngrok/mantle/icon";
import { SplitButton } from "@ngrok/mantle/split-button";

<SplitButton.Root>
	<SplitButton.PrimaryAction icon={<DownloadIcon />}>Download</SplitButton.PrimaryAction>
	<SplitButton.MenuTrigger label="Open download options" />
	<SplitButton.MenuContent>
		<SplitButton.MenuItem>
			<Icon svg={<DownloadIcon />} />
			Download as PDF
		</SplitButton.MenuItem>
		<SplitButton.MenuItem asChild>
			<a href="https://example.com" target="_blank" rel="noopener noreferrer">
				<Icon svg={<FileTextIcon />} />
				Open in new tab
			</a>
		</SplitButton.MenuItem>
	</SplitButton.MenuContent>
</SplitButton.Root>;
```

</Example>

## API Reference

### SplitButton.Root

A button group that pairs a one-click default action with a dropdown menu of related alternatives.

All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes), plus:

| Prop            | Type                                           | Default | Description                                                                                                                       |
| --------------- | ---------------------------------------------- | ------- | --------------------------------------------------------------------------------------------------------------------------------- |
| `dir?`          | `"ltr"` \| `"rtl"`                             |         | The reading direction of the dropdown menu.                                                                                       |
| `open?`         | `boolean`                                      |         | The controlled open state of the dropdown menu.                                                                                   |
| `defaultOpen?`  | `boolean`                                      |         | The open state of the dropdown menu when it is initially rendered.                                                                |
| `onOpenChange?` | `(open: boolean) => void`                      |         | Event handler called when the open state of the dropdown changes.                                                                 |
| `modal?`        | `boolean`                                      | `false` | Whether the dropdown menu is modal: the rest of the page is `inert` while it is open.                                             |
| `size?`         | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"` | `"md"`  | The size of the `SplitButton`. Applied to both the primary action and the menu trigger so the two halves always share one height. |

#### Data attributes

| Data Attribute | Value                                          | Description                                   |
| -------------- | ---------------------------------------------- | --------------------------------------------- |
| `data-slot`    | `"split-button"`                               | On the wrapping `<div>`.                      |
| `data-size`    | `"xs"` \| `"sm"` \| `"md"` \| `"lg"` \| `"xl"` | The `size` prop, which both halves render at. |

### SplitButton.PrimaryAction

The most common action users can trigger with a single click. Renders as a `Button` with `appearance="outlined"` and `intent="neutral"`.

All props from [`Button`](/components/actions/button), except `appearance`, `intent`, and `size` (set `size` on `SplitButton.Root` instead).

| Prop    | Type                                  | Default    | Description                       |
| ------- | ------------------------------------- | ---------- | --------------------------------- |
| `type?` | `"button"` \| `"submit"` \| `"reset"` | `"button"` | The type attribute of the button. |

### SplitButton.MenuTrigger

The button that opens the split button dropdown menu. Renders as an `IconButton` with a caret-down icon that rotates when the menu is open.

All props from [`IconButton`](/components/actions/icon-button), except `appearance`, `intent`, `size` (set `size` on `SplitButton.Root` instead), `asChild`, and `icon` (which is redefined as optional below).

| Prop    | Type                                  | Default         | Description                                              |
| ------- | ------------------------------------- | --------------- | -------------------------------------------------------- |
| `icon?` | `ReactNode`                           | Caret-down icon | Custom icon to render instead of the default caret-down. |
| `type?` | `"button"` \| `"submit"` \| `"reset"` | `"button"`      | The type attribute of the button.                        |

### SplitButton.MenuContent

The container for the split button dropdown menu content. Appears in a portal with scrolling and animations. Wraps `DropdownMenu.Content`.

All props from [`DropdownMenu.Content`](/components/overlays/dropdown-menu).

| Prop     | Type                                   | Default  | Description                                                                                                                                                                                                                                                                                             |
| -------- | -------------------------------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `align?` | `"start"` \| `"center"` \| `"end"`     | `"end"`  | The preferred alignment against the split button, or against the menu trigger with `width="trigger"` or `width="content"`.                                                                                                                                                                              |
| `width?` | `"root"` \| `"trigger"` \| `"content"` | `"root"` | The width of the menu. `"root"` is at least the width of the whole split button, and wider when an item needs it. `"trigger"` is the width of the menu trigger. `"content"` is the width of the widest item. Each keeps an 8rem minimum; `"root"` also never passes the viewport less 8px on each side. |

### SplitButton.MenuItem

A standard item in the split button dropdown menu that can be selected or activated. Wraps `DropdownMenu.Item` with `gap-2` styling.

All props from [`DropdownMenu.Item`](/components/overlays/dropdown-menu).

| Prop       | Type      | Default | Description                                                                                         |
| ---------- | --------- | ------- | --------------------------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose onto alternative element types like anchors or custom components. |
