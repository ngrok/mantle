<PageHeader id="breadcrumb">Breadcrumb</PageHeader>

Hierarchy-path navigation per the [WAI-ARIA breadcrumb pattern](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/): an ordered list of links from a root to the current page, inside a `<nav>` landmark labeled "Breadcrumb". Use it on detail pages inside deep hierarchies — an endpoint under a project under an account — so users can see how they got here and jump back up a level. It answers a different intent than [Tabs](/components/navigation/tabs), which switches _what you're looking at_ within one place; a breadcrumb tells you _where you are_ and offers the way up. It is router-agnostic — each `Breadcrumb.Link` is a plain `<a>` you can compose onto your router's link via `asChild` (see [Polymorphism](#polymorphism)), and [Anchor](/components/navigation/anchor) remains the right primitive for standalone external links.

## Composition

```text showLineNumbers=false
Breadcrumb.Root
└── Breadcrumb.List
    ├── Breadcrumb.Item
    │   └── Breadcrumb.Link
    ├── Breadcrumb.Separator
    ├── Breadcrumb.Item
    │   └── Breadcrumb.Label
    ├── Breadcrumb.Separator
    └── Breadcrumb.Item
        └── Breadcrumb.Page
```

- **`Root`** is the `<nav>` landmark, labeled `"Breadcrumb"` by default (overridable via `aria-label`). It carries no visual styling of its own.
- **`List`** is the `<ol>` — an ordered list, because the order of the items **is** the hierarchy, from the root to the current page. It lays the crumbs out in one row and scrolls them sideways when the trail is wider than its container (see [Overflow](#overflow)).
- **`Item`** is one crumb: an `<li>` wrapping a `Link`, a `Label`, or the `Page`.
- **`Link`** is a plain `<a>` to an ancestor page; compose it onto your router's link via `asChild`.
- **`Label`** is a crumb that is not a link — a level with no page of its own (see [The prefix crumb](#the-prefix-crumb)). A `<span>` with no `aria-current`.
- **`Page`** marks the current page — a `<span>` with `aria-current="page"`, not a link.
- **`Separator`** is a purely visual divider between crumbs (`role="presentation"`, `aria-hidden`), rendering a caret by default.

## Polymorphism

Every part supports `asChild`. The one that matters most is `Breadcrumb.Link`: the component never imports a router, so compose the link styling onto your framework's link — a `react-router` `Link` here — to get client-side navigation:

</Example>

```tsx
import { Breadcrumb } from "@ngrok/mantle/breadcrumb";

<Breadcrumb.Root>

		<Breadcrumb.Item>

		<Breadcrumb.Separator />
		<Breadcrumb.Item>
			<Breadcrumb.Page>Breadcrumb</Breadcrumb.Page>
		</Breadcrumb.Item>
	</Breadcrumb.List>
</Breadcrumb.Root>;
```

## The prefix crumb

Not every crumb is a destination. In a trail like `Settings > General`, `Settings` is a section prefix: its index URL only redirects to `/settings/general`, so a link there would bounce the user back to the page they are already on. Render that crumb as a `Breadcrumb.Label` — muted text like the rest of the trail, with no `href` and no `aria-current`:

<Example>
	<BreadcrumbPrefixCrumbExample />
</Example>

```tsx
import { Breadcrumb } from "@ngrok/mantle/breadcrumb";

<Breadcrumb.Root>
	<Breadcrumb.List>
		<Breadcrumb.Item>
			<Breadcrumb.Label>Settings</Breadcrumb.Label>
		</Breadcrumb.Item>
		<Breadcrumb.Separator />
		<Breadcrumb.Item>
			<Breadcrumb.Page>General</Breadcrumb.Page>
		</Breadcrumb.Item>
	</Breadcrumb.List>
</Breadcrumb.Root>;
```

The label stays an `Item` in the `<ol>`, so it still counts as a step in the trail — assistive technology reads it as a crumb, without offering it as a link. To derive a trail like this from your route tree, see [the prefix crumb in the breadcrumbs-from-routes recipe](/recipes/breadcrumbs-from-routes#the-prefix-crumb): a layout route contributes the label, and its child routes contribute the pages under it.

## Overflow

An app header is one row tall, so a trail wider than that row scrolls sideways instead of wrapping onto a second one. `Breadcrumb.List` is the scroll container, and its edges carry the same [`scroll-fade-x`](/base/scroll-fade#horizontal--scroll-fade-x) mask as [Tabs](/components/navigation/tabs): the edge with crumbs beyond it fades out, and the edge with nothing beyond it stays flush.

The trail starts at its end, because the end is the current page. It scrolls itself there whenever that end moves — on mount, when a navigation swaps the crumbs, and when the row around it resizes — and leaves the reader's own scroll position alone the rest of the time, including while a crumb holds focus. Tabbing to a crumb the trail has scrolled past is the browser's own job; the list carries `scroll-padding` the width of the fade zone, so that crumb lands clear of the fade rather than under it.

For this to work inside a flex row such as [`AppLayout.Header`](/layouts/app-layout#applayoutheader), `Breadcrumb.Root` carries `min-w-0`: the landmark gives up width to the row instead of pushing its siblings out of it. The crumbs themselves never shrink, so a crumb keeps its label on one line.

<Example>
	<BreadcrumbOverflowExample />
</Example>

```tsx
import { Breadcrumb } from "@ngrok/mantle/breadcrumb";

<div className="border-card-muted bg-card flex w-full max-w-sm items-center gap-2 rounded-lg border px-4 py-3">
	<Breadcrumb.Root>
		<Breadcrumb.List>
			<Breadcrumb.Item>
				<Breadcrumb.Link href="/">Acme Corp</Breadcrumb.Link>
			</Breadcrumb.Item>
			<Breadcrumb.Separator />
			<Breadcrumb.Item>
				<Breadcrumb.Link href="/endpoints">Endpoints</Breadcrumb.Link>
			</Breadcrumb.Item>
			<Breadcrumb.Separator />
			<Breadcrumb.Item>
				<Breadcrumb.Link href="/endpoints/cloud">Cloud Endpoints</Breadcrumb.Link>
			</Breadcrumb.Item>
			<Breadcrumb.Separator />
			<Breadcrumb.Item>
				<Breadcrumb.Link href="/endpoints/cloud/policy">Traffic Policy</Breadcrumb.Link>
			</Breadcrumb.Item>
			<Breadcrumb.Separator />
			<Breadcrumb.Item>
				<Breadcrumb.Page>ep_2h8xyz</Breadcrumb.Page>
			</Breadcrumb.Item>
		</Breadcrumb.List>
	</Breadcrumb.Root>
</div>;
```

Two constraints come with the mask, both covered in full on the [scroll fade](/base/scroll-fade) page:

- The mask fades everything `Breadcrumb.List` paints, its own background and border included. Keep that styling on a wrapper, as the example above does.
- The mask owns the element's `mask-image`. A second mask on the same element replaces it.

To wrap instead, hand the scrollport back:

```tsx
<Breadcrumb.List className="flex-wrap overflow-x-visible">
```

The mask needs a scroll container to animate against. Without one it stays fully opaque, and the row wraps as it did before.

## Accessibility

Breadcrumb follows the [APG breadcrumb pattern](https://www.w3.org/WAI/ARIA/apg/patterns/breadcrumb/):

- The trail lives in a `<nav>` landmark labeled `"Breadcrumb"`, so screen reader users can jump straight to it. The label is overridable via `aria-label` on `Root` — do so for localization, or to distinguish multiple breadcrumb trails on one page.
- The crumbs are an `<ol>`, so assistive technology announces the total count and each item's position — the order conveys the hierarchy.
- The final crumb is a `Breadcrumb.Page` with `aria-current="page"`, announcing that it represents the current page. It is a `<span>`, not a link — linking to the page you are already on is a trap.
- A `Breadcrumb.Label` crumb is plain text: no link role, no `aria-current`. Its `Item` stays in the `<ol>`, so screen readers count it as a step in the trail without offering it as a destination.
- Separators are `role="presentation"` and `aria-hidden="true"`: purely visual, never counted as crumbs, never read aloud.

## API Reference

### Breadcrumb.Root

The `<nav>` landmark containing the trail. It carries no visual styling; its one layout class is `min-w-0`, which lets the landmark shrink inside a flex row so `Breadcrumb.List` scrolls (see [Overflow](#overflow)).

All props from [nav](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/nav#attributes), plus:

| Prop          | Type      | Default        | Description                                                                                                             |
| ------------- | --------- | -------------- | ----------------------------------------------------------------------------------------------------------------------- |
| `aria-label?` | `string`  | `"Breadcrumb"` | The accessible name of the landmark. Override for localization or when a page has multiple breadcrumb trails.           |
| `asChild?`    | `boolean` | `false`        | Use the `asChild` prop to compose the `Breadcrumb` styling onto alternative element types or your own React components. |

### Breadcrumb.List

The ordered list of crumbs — the order is the hierarchy. It is also the scroll container: a trail wider than its container scrolls sideways with a faded edge and starts at the current page, and `className="flex-wrap overflow-x-visible"` trades that back for wrapping (see [Overflow](#overflow)).

All props from [ol](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/ol#attributes), plus:

| Prop       | Type      | Default | Description                                                                                                                  |
| ---------- | --------- | ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose the `Breadcrumb.List` styling onto alternative element types or your own React components. |

### Breadcrumb.Item

A single crumb wrapping a `Link` or the `Page`. The crumb never shrinks, so it keeps its label on one line and the trail scrolls instead.

All props from [li](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/li#attributes), plus:

| Prop       | Type      | Default | Description                                                                                                                  |
| ---------- | --------- | ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose the `Breadcrumb.Item` styling onto alternative element types or your own React components. |

### Breadcrumb.Link

A link to an ancestor page in the hierarchy.

All props from [a](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/a#attributes), plus:

| Prop       | Type      | Default | Description                                                                                                                                                         |
| ---------- | --------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose the `Breadcrumb.Link` styling onto alternative element types or your own React components — most commonly your app router's link. |

### Breadcrumb.Label

A crumb that is not a link — a level with no page of its own, such as a section whose index URL only redirects (see [The prefix crumb](#the-prefix-crumb)). It emits no `aria-current` and no link semantics.

All props from [span](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/span#attributes), plus:

| Prop       | Type      | Default | Description                                                                                                                   |
| ---------- | --------- | ------- | ----------------------------------------------------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose the `Breadcrumb.Label` styling onto alternative element types or your own React components. |

### Breadcrumb.Page

The current page — the last crumb. Always emits `aria-current="page"`.

All props from [span](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/span#attributes), plus:

| Prop       | Type      | Default | Description                                                                                                                  |
| ---------- | --------- | ------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose the `Breadcrumb.Page` styling onto alternative element types or your own React components. |

### Breadcrumb.Separator

A purely visual divider between crumbs, hidden from assistive technology. Like the crumbs it divides, it never shrinks.

All props from [li](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/li#attributes), plus:

| Prop        | Type        | Default                                                  | Description                                                                                                                                                                      |
| ----------- | ----------- | -------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `children?` | `ReactNode` | `<Icon svg={<CaretRightIcon />} className="size-3.5" />` | The separator glyph. Defaults to a size-3.5 caret icon; pass your own children (e.g. a slash) to replace it. Required when `asChild` is set — the child element is what renders. |
| `asChild?`  | `boolean`   | `false`                                                  | Use the `asChild` prop to compose the `Breadcrumb.Separator` styling onto alternative element types or your own React components. Requires `children`.                           |
