# Media Object

The Media Object is an image or an icon (media) on the left, with descriptive content (a title and a subtitle or description) on the right. Compose `MediaObject.Media` and `MediaObject.Content` as direct children of `MediaObject.Root`.

<Example>
	<MediaObject.Root>
		<MediaObject.Media>
			<ExampleMedia />
		</MediaObject.Media>
		<MediaObject.Content>
			<h4 className="text-lg font-medium">Lorem ipsum</h4>
			<p className="mb-4 mt-1">
				Repudiandae sint consequuntur vel. Amet ut nobis explicabo numquam expedita quia omnis
				voluptatem. Minus quidem ipsam quia iusto.
			</p>
			<p>Ea eiusmod eiusmod aute reprehenderit exercitation eu ea id adipisicing occaecat.</p>
		</MediaObject.Content>
	</MediaObject.Root>
</Example>

```tsx
import { MediaObject } from "@ngrok/mantle/media-object";

<MediaObject.Root>
	<MediaObject.Media>
		<ExampleMedia />
	</MediaObject.Media>
	<MediaObject.Content>
		<h4 className="text-lg font-medium">Lorem ipsum</h4>

		</p>
		<p>Ea eiusmod eiusmod aute reprehenderit exercitation eu ea id adipisicing occaecat.</p>
	</MediaObject.Content>

```

## When to use

- Put an avatar beside a name and a body in a comment thread.
- Put an icon beside a label and secondary text in a compact list item or a notification row.
- Build feature lists, profile cards, and attachment previews.
- Leave out the media when it is decorative and adds no information. Use a plain block instead.
- Prefer [`Card`](/components/structure/card) for a raised box with a border, or for a complex layout with many regions. You can also build your own flex or grid layout for that.
- Prefer [`Choice`](/components/forms/choice) when the thing beside the text is a checkbox, a radio, or a switch.

## Composition

Compose the parts of a `MediaObject` together to build your own:

```text showLineNumbers=false
MediaObject.Root
├── MediaObject.Media
└── MediaObject.Content
```

## Polymorphism

Each part accepts an `asChild` prop. When `true`, the part renders its single child instead of its default `<div>`, forwarding its styling and props onto that child. Render `MediaObject.Root` as an `<a>` to make the whole row a link.

<Example>
	<MediaObject.Root asChild>
		<a href="https://ngrok.com">
			<MediaObject.Media>
				<ExampleMedia />
			</MediaObject.Media>
			<MediaObject.Content>
				<h4 className="text-lg font-medium">Lorem ipsum</h4>
				<p>Repudiandae sint consequuntur vel.</p>
			</MediaObject.Content>
		</a>
	</MediaObject.Root>
</Example>

```tsx
import { MediaObject } from "@ngrok/mantle/media-object";

<MediaObject.Root asChild>
	<a href="https://ngrok.com">
		<MediaObject.Media>
			<ExampleMedia />
		</MediaObject.Media>
		<MediaObject.Content>
			<h4 className="text-lg font-medium">Lorem ipsum</h4>
			<p>Repudiandae sint consequuntur vel.</p>
		</MediaObject.Content>
	</a>
</MediaObject.Root>;
```

## Spacing & alignment

Default gap is `gap-4`; override by passing a different `gap-*` class to `MediaObject.Root`. Use standard flex utilities (`items-start`, `items-center`, etc.) to align media and content vertically.

## The media object pattern

`MediaObject` is a small layout primitive for the [media object pattern](https://www.stubbornella.org/2010/06/25/the-media-object-saves-hundreds-of-lines-of-code/): media on one side, and descriptive content on the other. Use it for each two-up row, so you do not write the same flexbox again.

## API Reference

### MediaObject.Root

The `MediaObject` is an image/icon (media) to the left, with descriptive content (title and subtitle/description) to the right. Root container for all `MediaObject.Root` sub-components.

All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes), plus:

| Prop      | Type      | Default | Description                                                                                                                                |
| --------- | --------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `asChild` | `boolean` | `false` | Use the `asChild` prop to compose the `MediaObject` styling and functionality onto alternative element types or your own React components. |

### MediaObject.Media

The container for an image or icon to display in the media slot of the `MediaObject`.

All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes), plus:

| Prop      | Type      | Default | Description                                                                                                                                      |
| --------- | --------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| `asChild` | `boolean` | `false` | Use the `asChild` prop to compose the `MediaObject.Media` styling and functionality onto alternative element types or your own React components. |
