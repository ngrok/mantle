# Separator

Visually or semantically separates content.

<CodeExample.Root>
	<CodeExample.PreviewFrame example="components/structure/separator/overview" title="Separator example" />
	<CodeExample.Code>

```tsx

	</div>
	<Separator className="my-4" />
	<p className="text-sm">Build ngrok interfaces with shared components.</p>
</div>;
```

    </CodeExample.Code>

## When to use

- Divide adjacent content without a box, in a row or in a column.
- Put a text label in the middle or at one end of a horizontal divider: wrap the label and the separators in a `HorizontalSeparatorGroup`.
- Prefer [`Card`](/components/structure/card) when the content needs a border on every side.
- Prefer [`Well`](/components/structure/well) when the content needs a recessed background, not a line.
- Prefer [`DescriptionList`](/components/data-display/description-list) when the content is key and value pairs, which carry their own rows.

## Vertical

Set `orientation="vertical"` to divide items in a row. The parent sets the height.

<CodeExample.Root>
	<CodeExample.PreviewFrame example="components/structure/separator/vertical" title="Separator vertical example" />

```tsx
import { Separator } from "@ngrok/mantle/separator";

<div className="flex h-5 items-center gap-4 text-sm">
	Blog
	<Separator orientation="vertical" />
	Docs
	<Separator orientation="vertical" />
	Source
</div>;
```

    </CodeExample.Code>

## Semantic

A separator is decorative by default, and assistive technology skips it. Set `semantic` when the line marks a real boundary between two groups of content: it renders `role="separator"`.

<CodeExample.Root>
	<CodeExample.PreviewFrame example="components/structure/separator/semantic" title="Separator semantic example" />
	<CodeExample.Code>

```tsx
import { Separator } from "@ngrok/mantle/separator";

<div className="w-full max-w-sm text-sm">
	<p>Account settings</p>
	<Separator className="my-4" semantic />
	<p>Danger zone</p>
</div>;
```

    </CodeExample.Code>

</CodeExample.Root>

## Labeled divider

Wrap a label and one or two separators in a `HorizontalSeparatorGroup` to put the label in the middle or at one end of the line.

<CodeExample.Root>
	<CodeExample.PreviewFrame example="components/structure/separator/labeled-divider" title="Separator labeled divider example" />
	<CodeExample.Code>

```tsx
import { HorizontalSeparatorGroup, Separator } from "@ngrok/mantle/separator";

<div className="w-full max-w-sm space-y-4">
	<HorizontalSeparatorGroup>
		<Separator />
		<h3>ngrok mantle</h3>
		<Separator />
	</HorizontalSeparatorGroup>
	<HorizontalSeparatorGroup>
		<h3>ngrok mantle</h3>
		<Separator />
	</HorizontalSeparatorGroup>
	<HorizontalSeparatorGroup>
		<Separator />
		<h3>ngrok mantle</h3>
	</HorizontalSeparatorGroup>
</div>;
```

    </CodeExample.Code>

</CodeExample.Root>

## Polymorphism

When you want to render _something else_ as a `HorizontalSeparatorGroup` or `Separator`, you can use the `asChild` prop to compose.

<CodeExample.Root>
	<CodeExample.PreviewFrame example="components/structure/separator/polymorphism" title="Separator polymorphism example" />
	<CodeExample.Code>

```tsx
import { HorizontalSeparatorGroup, Separator } from "@ngrok/mantle/separator";

<form>
	<fieldset className="space-y-4">
		<HorizontalSeparatorGroup className="w-full" asChild>
			<legend>
				Choose your favorite fruit!
				<Separator asChild>
					<span />
				</Separator>
			</legend>
		</HorizontalSeparatorGroup>
		<div className="space-y-2">
			<div className="space-x-2">
				<input type="radio" id="apple" name="monster" value="apple" />
				<label htmlFor="apple">Apple</label>
			</div>
			<div className="space-x-2">
				<input type="radio" id="mango" name="monster" value="mango" />
				<label htmlFor="mango">Mango</label>
			</div>
			<div className="space-x-2">
				<input type="radio" id="pear" name="monster" value="pear" />
				<label htmlFor="pear">Pear</label>
			</div>
		</div>
	</fieldset>
</form>

<div className="flex h-5 items-center space-x-4 text-sm">
	<div>Blog</div>
	<Separator orientation="vertical" asChild>
		<span />
	</Separator>
	<div>Docs</div>
	<Separator orientation="vertical" asChild>
		<span />
	</Separator>
	<div>Source</div>
</div>
```

    </CodeExample.Code>

</CodeExample.Root>

## Color

The separator renders in the semantic `separator` color token: `gray-500/20` in light and `gray-600/20` in dark.
This is the canonical divider color across mantle: `Accordion` dividers,
`DropdownMenu.Separator`, `Command.Separator`, `Select.Separator`, and the rest all resolve to it.

Reuse the same color on your own dividers instead of hard-coding it:

<CodeExample.Root>

## API Reference

### Separator

Visually or semantically separates content.

All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes), plus:

| Prop           | Type                           | Default        | Description                                                                                                                                                                                                                                                                 |
| -------------- | ------------------------------ | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `orientation?` | `"horizontal"` \| `"vertical"` | `"horizontal"` | The orientation of the separator, does it render horizontally or vertically.                                                                                                                                                                                                |
| `semantic?`    | `boolean`                      | `false`        | If `true`, the separator renders with all accessibility-related attributes and `role="separator"`. If `false`, the separator is purely decorative and all accessibility-related attributes are updated so that the rendered element is removed from the accessibility tree. |
| `asChild?`     | `boolean`                      | `false`        | Use the `asChild` prop to compose the `Separator` styling and functionality onto alternative element types or your own React components.                                                                                                                                    |

| Data Attribute     | Value                          | Description                                                        |
| ------------------ | ------------------------------ | ------------------------------------------------------------------ |
| `data-slot`        | `"separator"`                  | Names the part.                                                    |
| `data-orientation` | `"horizontal"` \| `"vertical"` | The resolved orientation, after a `HorizontalSeparatorGroup` wins. |
| `data-separator`   | present                        | Presence-only. Lets a group exempt separators from `shrink-0`.     |

### HorizontalSeparatorGroup

A container to layout a group of horizontal separators and other children.
Overrides all children `Separator`s to be `orientation="horizontal"`.
All props from [div](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/div#attributes), plus:

| Prop       | Type      | Default | Description                                                                                                                                             |
| ---------- | --------- | ------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `asChild?` | `boolean` | `false` | Use the `asChild` prop to compose the `HorizontalSeparatorGroup` styling and functionality onto alternative element types or your own React components. |

| Data Attribute                    | Value                          | Description                                       |
| --------------------------------- | ------------------------------ | ------------------------------------------------- |
| `data-slot`                       | `"horizontal-separator-group"` | Names the part.                                   |
| `data-horizontal-separator-group` | present                        | Presence-only. Child separators stretch under it. |
