# Query Input from the URL

A filtered list is worth sharing. Put the query in `?q=` and the link you paste into Slack opens the same list. [Query Input](/components/forms/query-input) is controlled only, so the URL state is yours to wire, and mantle never imports a router. This recipe is one small hook.

Two rules shape it:

- The typed text is the source of truth while you type. Bind the field straight to the URL and every keystroke is a navigation, so the URL write waits 250 ms after the last edit and replaces the history entry instead of pushing one.
- A URL change from outside (the back button, a link to `?q=is:custom`) replaces the typed text. The hook compares the URL value with the one it saw last render and resets the text during render, not in an effect.

Type a filter below and watch the address bar.

```tsx
import { filterItemsByQuery } from "@ngrok/mantle/query-filter";
import { QueryInput } from "@ngrok/mantle/query-input";
import { useDeferredValue } from "react";
import { domainFilterGrammar, domains } from "~/features/query-input-demos";
import { useQueryParamInput } from "~/features/query-input-url-state";

export function QueryInputFromUrlDemo() {
	const { query, setQuery } = useQueryParamInput();
	const deferredQuery = useDeferredValue(query);
	const visibleDomains = filterItemsByQuery({
		grammar: domainFilterGrammar,
		items: domains,
		query: deferredQuery,
	});

	return (
		<div className="w-full max-w-xl space-y-3">
			<QueryInput.Root
				grammar={domainFilterGrammar}
				items={domains}
				value={query}
				onValueChange={setQuery}
			>
				<QueryInput.Field
					aria-label="Filter domains"
					placeholder="Filter domains, or type a filter like is:custom"
				/>
				<QueryInput.BuilderMenu label="Add filter" />
				<QueryInput.Content />
			</QueryInput.Root>
			<ul aria-label="Domains" className="divide-y rounded-md border">
				{visibleDomains.map((domain) => (
					<li key={domain.id} className="px-3 py-2 font-mono text-sm">
						{domain.name}
					</li>
				))}
			</ul>
		</div>
	);
}
```

## The hook with React Router

Copy this file. It uses `useSearchParams` from `react-router` and `useDebouncedCallback` from `@ngrok/mantle/hooks`.

````tsx
import { useDebouncedCallback } from "@ngrok/mantle/hooks";
import { useState } from "react";
import { useSearchParams } from "react-router";

/**
 * Owns the typed text of a `QueryInput` and keeps it in the `?q=` URL param,
 * so a filtered list is shareable by its URL.
 *
 * The typed text is the source of truth while you type: the URL write waits
 * 250 ms after the last edit and replaces the history entry. A URL change from
 * outside, such as the back button, replaces the typed text.
 *
 * @example
 * ```tsx
 * const { query, setQuery } = useQueryParamInput();
 * <QueryInput.Root grammar={grammar} items={items} value={query} onValueChange={setQuery}>…</QueryInput.Root>
 * ```
 */
export function useQueryParamInput() {
	const [searchParams, setSearchParams] = useSearchParams();
	const urlQuery = searchParams.get("q") ?? "";
	const [query, setQuery] = useState(urlQuery);
	const [previousUrlQuery, setPreviousUrlQuery] = useState(urlQuery);
	if (urlQuery !== previousUrlQuery) {
		setPreviousUrlQuery(urlQuery);
		setQuery(urlQuery);
	}

	const writeUrlQuery = useDebouncedCallback(
		(nextQuery: string) => {
			setSearchParams(
				(current) => {
					const next = new URLSearchParams(current);
					if (nextQuery === "") {
						next.delete("q");
					} else {
						next.set("q", nextQuery);
					}
					return next;
				},
				{ replace: true, preventScrollReset: true },
			);
		},
		{ waitMs: 250 },
	);

	return {
		query,
		setQuery: (nextQuery: string) => {
			setQuery(nextQuery);
			writeUrlQuery(nextQuery);
		},
	};
}
````

Filter with `useDeferredValue(query)`, as the demo does, so a long list re-renders behind the keystroke instead of in front of it. If the list loads through TanStack Query, filter inside `select` and keep the query key unfiltered, so one cache entry serves every query.

## The hook with nuqs

With [nuqs](https://nuqs.dev), `useQueryState` owns the URL write, and its `throttleMs` option takes the place of the debounce. This docs site doesn't use nuqs, so nothing on this page runs this version.

```tsx showLineNumbers=false
import { parseAsString, useQueryState } from "nuqs";
import { useState } from "react";

const queryParam = parseAsString
	.withDefault("")
	.withOptions({ clearOnDefault: true, throttleMs: 250 });

export function useQueryParamInput() {
	const [urlQuery, setUrlQuery] = useQueryState("q", queryParam);
	const [query, setQuery] = useState(urlQuery);
	const [previousUrlQuery, setPreviousUrlQuery] = useState(urlQuery);
	if (urlQuery !== previousUrlQuery) {
		setPreviousUrlQuery(urlQuery);
		setQuery(urlQuery);
	}

	return {
		query,
		setQuery: (nextQuery: string) => {
			setQuery(nextQuery);
			void setUrlQuery(nextQuery);
		},
	};
}
```
