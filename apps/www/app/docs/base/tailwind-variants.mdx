# Tailwind Variants

Mantle registers these Tailwind variants with `@custom-variant` in `mantle.css`.

## Theme

| Variant  | Description                                                                                                                                                                                         |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `light:` | Applies a class when the light theme is active.                                                                                                                                                     |
| `dark:`  | Applies a class when the dark theme is active. Replaces Tailwind's built-in `dark:`: it matches the theme mantle applies (a `.dark` class or a `data-theme` attribute), not `prefers-color-scheme`. |

## Hover media queries

|                                                                         | Variant        | Description                                                                                                                                            |
| ----------------------------------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| <VariantIndicator show="hover-hover:block" hide="hover-hover:hidden" /> | `hover-hover:` | Applies a class on a device that can hover, whether or not the pointer is over the element. Tailwind's `hover:` also needs the pointer on the element. |
| <VariantIndicator show="hover-none:block" hide="hover-none:hidden" />   | `hover-none:`  | Applies a class on a device that can't hover.                                                                                                          |

## ARIA

| Variant           | Description                                    |
| ----------------- | ---------------------------------------------- |
| `aria-collapsed:` | Matches elements with `aria-expanded="false"`. |
| `aria-invalid:`   | Matches elements with `aria-invalid="true"`.   |
| `aria-unchecked:` | Matches elements with `aria-checked="false"`.  |

## Data attributes

Mantle registers no `data-*` variants. Its components emit plain attributes, so style them with the variants Tailwind ships:

- Match a boolean state with its name, such as `data-open:`, and its absence with `not-data-open:`. A boolean attribute is presence-only: it's there (`""`) or it's gone, and it's never `"false"`.
- Match an enum with the bracket form, such as `data-[side=top]:` for `data-side="top"`.
- Match state that HTML or ARIA already carries with `aria-expanded:`, `aria-selected:`, `aria-checked:`, `aria-disabled:`, or `disabled:`.
- Match a parent's state from a child with a `group-` form, such as `group-data-open:` or `group-aria-expanded:`.

```tsx
<Popover.Content className="data-open:animate-in not-data-open:animate-out" />
<Tooltip.Content className="data-[side=top]:mb-2" />
<button type="button" aria-expanded={open} className="group">
	Details
	<CaretDownIcon className="group-aria-expanded:rotate-180" />
</button>
```

| Attribute            | Where mantle emits it                                                                     | Variant                                |
| -------------------- | ----------------------------------------------------------------------------------------- | -------------------------------------- |
| `data-open`          | Open overlays and content: popovers, menus, dialogs, accordion items                      | `data-open:`, `not-data-open:`         |
| `data-closing`       | `<dialog>` surfaces (Dialog, AlertDialog, Sheet, the mobile sidebar) while the exit plays | `data-closing:`                        |
| `data-expanded`      | The `Sidebar.Nav` desktop panel                                                           | `data-expanded:`, `not-data-expanded:` |
| `data-highlighted`   | The option or row that the keyboard or pointer is on                                      | `data-highlighted:`                    |
| `data-selected`      | Selected `List` rows and the chosen `Combobox` row                                        | `data-selected:`                       |
| `data-placeholder`   | A `Select` trigger with no value                                                          | `data-placeholder:`                    |
| `data-loading`       | `Button`, `IconButton`, and `ThemeSwitcher` while loading                                 | `data-loading:`                        |
| `data-indeterminate` | `ProgressBar` and `ProgressDonut` while indeterminate                                     | `data-indeterminate:`                  |
| `data-engaged`       | Chart and `WorldMap` roots once focus lands inside                                        | `data-engaged:`                        |
| `data-drag-over`     | `TextArea` while something is dragged over it                                             | `data-drag-over:`                      |
| `data-x-overflow`    | `Table` when its content is wider than the container                                      | `data-x-overflow:`                     |
| `data-disabled`      | `Label` and the `Input`, `PasswordInput`, and `Query` chrome                              | `data-disabled:`                       |
| `data-side`          | Floating content, such as tooltips and popovers                                           | `data-[side=top]:`                     |
| `data-validation`    | Form controls with a validation state                                                     | `data-[validation=error]:`             |
| `data-orientation`   | Component roots that lay out in either direction                                          | `data-[orientation=vertical]:`         |
| `aria-expanded`      | Triggers for dialogs, popovers, menus, selects, accordions, and the sidebar               | `aria-expanded:`, `aria-collapsed:`    |
| `aria-selected`      | Tabs triggers and listbox options                                                         | `aria-selected:`                       |
| `aria-checked`       | Checkable menu items                                                                      | `aria-checked:`, `aria-unchecked:`     |
