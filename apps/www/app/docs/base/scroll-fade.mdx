# Scroll Fade

Edge-fade utilities for scroll containers. An edge with more content past it
fades out. At the end of the scroll, or when nothing overflows, the edge stays
fully opaque.

The fade is CSS only: a [scroll-driven animation](https://developer.mozilla.org/en-US/docs/Web/CSS/animation-timeline/scroll)
runs it.

> [!NOTE]
> A browser without `animation-timeline: scroll()` support (Firefox before 159)
> shows no fade. It never clips the content.

## Both edges

### Vertical (`scroll-fade-y`)

Fades the top and bottom edges of a vertically scrolling container. Scroll the
list to see each edge fade in and out.

<Example name="base/scroll-fade/vertical-scroll-fade-y" title="Scroll Fade vertical (scroll-fade-y) example">

```tsx
<div className="scroll-fade-y h-56 overflow-y-auto">{/* tall content */}</div>
```

</Example>

### Horizontal (`scroll-fade-x`)

Fades the left and right edges of a horizontally scrolling container.

<Example name="base/scroll-fade/horizontal-scroll-fade-x" title="Scroll Fade horizontal (scroll-fade-x) example">

```tsx
<div className="scroll-fade-x w-72 overflow-x-auto">{/* wide content */}</div>
```

</Example>

## Single edge

To fade only one edge, use a single-edge utility. A sidebar, for example, can
fade content under a sticky header and stay flush at the bottom. The opposite
edge always stays fully opaque.

| Utility         | Axis       | Fades       |
| --------------- | ---------- | ----------- |
| `scroll-fade-t` | vertical   | top edge    |
| `scroll-fade-b` | vertical   | bottom edge |
| `scroll-fade-l` | horizontal | left edge   |
| `scroll-fade-r` | horizontal | right edge  |

Use them exactly like the axis utilities: put the edge class on the scroll
container. The sidebar example above becomes:

```tsx
<nav className="scroll-fade-t h-full overflow-y-auto">{/* tall content */}</nav>
```

Each box below is pre-scrolled to its midpoint so the single faded edge stands
out against the flush opposite edge.

<Example name="base/scroll-fade/single-edge" title="Scroll Fade single edge example">

```tsx
<div className="scroll-fade-t h-44 overflow-y-auto">{/* tall content */}</div>
<div className="scroll-fade-b h-44 overflow-y-auto">{/* tall content */}</div>
<div className="scroll-fade-l overflow-x-auto">{/* wide content */}</div>
<div className="scroll-fade-r overflow-x-auto">{/* wide content */}</div>
```

</Example>

## Inside a border

`scroll-fade-y-inset` fades the same edges as `scroll-fade-y`, but only inside the border. The border and a focus ring stay solid. `TextArea` uses it. It needs scroll-driven animations and `mask-clip: no-clip`, and it shows no fade in an engine without them.

## Requirements

- Apply the utility to the scroll container itself: the element that has
  `overflow-x-auto` or `overflow-y-auto`. The fade follows that element's own
  scroll position.
- The utility sets `mask-image`, so don't put another `mask-image` on the same
  element.
- The mask fades _everything_ the element paints, border and background
  included. To fade the content of a visible card, put the `border`, the
  background, `rounded-*`, and `overflow-hidden` on a wrapper. Then put the fade
  utility on the inner scroll container, as the examples on this page do:

```tsx
<div className="overflow-hidden rounded-lg border border-card bg-card">
	<div className="scroll-fade-y h-56 overflow-y-auto">{/* tall content */}</div>
</div>
```
