# Typography

The type scale, text colors, and fonts for mantle UI.

## Scale

The type scale has two sets of steps: heading steps and paragraph steps. The steps follow Tailwind's `text-*` scale, from `xs` to `8xl`, and each step has the same default size as the Tailwind class of its name. Each step is a `text-*` class that sets the font size, line height, letter spacing, and weight together. A step is separate from the markup, so an `<h2>` can use any heading step. The [`Typography`](/components/data-display/typography) parts use these steps.

<p className="mt-4 text-heading-5xl font-heading">Heading 5xl</p>
<p className="mt-4 text-heading-3xl font-heading">Heading 3xl</p>
<p className="mt-4 text-heading-2xl font-heading">Heading 2xl</p>
<p className="mt-4 text-heading-xl font-heading">Heading xl</p>
<p className="mt-4 text-heading-base font-heading">Heading base</p>
<p className="mt-4 text-heading-xs font-heading uppercase tracking-widest">Heading xs</p>
<p className="mt-4 text-paragraph-xl">Paragraph xl</p>
<p className="mt-4 text-paragraph-lg">Paragraph lg</p>
<p className="mt-4 text-paragraph-base">Paragraph base</p>
<p className="mt-4 text-paragraph-sm">Paragraph sm</p>
<p className="mt-4 text-paragraph-xs">Paragraph xs</p>

| Steps                                     | Classes                                    | Weight | Line height               | Default part                                                                |
| ----------------------------------------- | ------------------------------------------ | ------ | ------------------------- | --------------------------------------------------------------------------- |
| Heading `xs`, `sm`, `base`, `lg` to `8xl` | `text-heading-xs` to `text-heading-8xl`    | 500    | Tailwind's, for each step | `H1`: `5xl`, `H2`: `3xl`, `H3`: `2xl`, `H4`: `xl`, `H5`: `base`, `H6`: `xs` |
| Paragraph `xs`, `sm`, `base`, `lg`, `xl`  | `text-paragraph-xs` to `text-paragraph-xl` | 400    | 1.625                     | `P`: `base`. Use `lg` for a lead paragraph.                                 |

`Typography.H6` also sets `uppercase` and `tracking-widest`.

Headings use the `font-heading` class. It's the page font (`font-sans`) unless a site sets its own.

### Set a site's scale

Each step is a theme variable, so a site sets its own scale in its stylesheet, after the mantle import. Your values replace mantle's on every page of the site, and the markup stays the same:

```css
@import "@ngrok/mantle/mantle.css";

@theme {
	--font-heading: "Your Display Font", Georgia, serif;
	--text-heading-5xl: clamp(2.5rem, 1.75rem + 3vw, 4.5rem);
	--text-heading-5xl--line-height: 1.05;
	--text-heading-5xl--letter-spacing: -0.02em;
	--text-heading-5xl--font-weight: 400;
}
```

Set all three sub-keys of a step you change: `--line-height`, `--letter-spacing`, and `--font-weight`. A sub-key you leave out keeps mantle's value, so a 4.5rem heading would keep a line height made for 3rem. To change the scale for one section of a page instead, set the same variables on that section's element.

## Colors

Color text with these tokens. They set hierarchy without a size change, and each one has a value for every theme.

<TypographyColors />

| Token       | Class               | Description                         |
| ----------- | ------------------- | ----------------------------------- |
| Strong      | `.text-strong`      | High emphasis, for primary content. |
| Body        | `.text-body`        | Default body text.                  |
| Muted       | `.text-muted`       | Low emphasis, for secondary text.   |
| Placeholder | `.text-placeholder` | Lowest emphasis, for placeholders.  |

## Fonts

Roobert is the default font for UI and headings. JetBrains Mono sets code, and Family sets long-form prose. A site can give headings their own font with `--font-heading`.

| Class         | Font family                                                                                      | Description                                                         |
| ------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| `font-sans`   | `"Roobert"`, `ui-sans-serif`, `system-ui`, `sans-serif`                                          | The page default, for UI and headings.                              |
| `font-family` | `"Family"`, `"Georgia"`, `serif`                                                                 | For long-form prose, such as documentation. Not for headings.       |
| `font-mono`   | `"JetBrains Mono"`, `ui-monospace`, `SFMono-Regular`, `Menlo`, `Monaco`, `Consolas`, `monospace` | For code and tokens. Set it one size step below the text around it. |
