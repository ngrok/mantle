# Typography

The type scale, text colors, and fonts for mantle UI.

## Scale

The type scale sets the size of each heading level. It's separate from the markup, so an `<h1>` can use the Heading 2 style when the layout needs it.

Headings don't set a font family. They inherit the body font, so keep `font-sans`, `font-family`, and
`font-mono` off them.

<p className="mt-4 text-5xl font-medium">Heading 1</p>
<p className="mt-4 text-3xl font-medium">Heading 2</p>
<p className="mt-4 text-2xl font-medium">Heading 3</p>
<p className="mt-4 text-xl font-medium">Heading 4</p>
<p className="mt-4 text-base font-medium">Heading 5</p>
<p className="mt-4 text-xs font-medium uppercase tracking-widest">Heading 6</p>

| Level     | Size        | Weight        | Additional                  |
| --------- | ----------- | ------------- | --------------------------- |
| Heading 1 | `text-5xl`  | `font-medium` |                             |
| Heading 2 | `text-3xl`  | `font-medium` |                             |
| Heading 3 | `text-2xl`  | `font-medium` |                             |
| Heading 4 | `text-xl`   | `font-medium` |                             |
| Heading 5 | `text-base` | `font-medium` |                             |
| Heading 6 | `text-xs`   | `font-medium` | `uppercase tracking-widest` |

## Colors

Color text with these tokens. They set hierarchy without a size change, and each one has a value for every theme.

<TypographyColors />

| Token       | Class               | Description                         |
| ----------- | ------------------- | ----------------------------------- |
| Strong      | `.text-strong`      | High emphasis, for primary content. |
| Body        | `.text-body`        | Default body text.                  |
| Muted       | `.text-muted`       | Low emphasis, for secondary text.   |
| Placeholder | `.text-placeholder` | Lowest emphasis, for placeholders.  |

## Fonts

Roobert is the default font for UI and headings. JetBrains Mono sets code, and Family sets long-form prose.

| Class         | Font family                                                                                      | Description                                                         |
| ------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------- |
| `font-sans`   | `"Roobert"`, `ui-sans-serif`, `system-ui`, `sans-serif`                                          | The page default, for UI and headings.                              |
| `font-family` | `"Family"`, `"Georgia"`, `serif`                                                                 | For long-form prose, such as documentation. Not for headings.       |
| `font-mono`   | `"JetBrains Mono"`, `ui-monospace`, `SFMono-Regular`, `Menlo`, `Monaco`, `Consolas`, `monospace` | For code and tokens. Set it one size step below the text around it. |
