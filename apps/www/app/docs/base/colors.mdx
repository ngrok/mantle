# Colors

Mantle's color tokens follow the theme. Write the light-mode class, and dark mode comes with it.

## Dark mode

Mantle styles with Tailwind but ships its own color palette. In dark mode, each ramp flips: `blue-400` takes the light-mode `blue-600` value, and `blue-600` takes `blue-400`. A class such as `bg-blue-600` keeps its contrast against the page in both themes, so it needs no `dark:` partner.

To set a different value in dark mode, add a [`dark:` class](https://tailwindcss.com/docs/dark-mode) as an override.

## Variables

Each color is a CSS variable in the `oklch()` color space. Use it through a Tailwind class (`text-blue-500`) or read it directly (`var(--color-blue-500)`).

## Black and white color variables

`black` and `white` are semantic colors, not literal ones. In dark mode, `white` resolves to black and `black` resolves to white. Switch the theme to see the swap:
