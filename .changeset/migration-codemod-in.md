The mantle MCP `migrate` tool now offers the codemod for migration guides 0014, 0015, 0017, 0018, 0019, 0021, and 0024. Those guides shipped a codemod but did not say which release shipped it, so the tool told you to migrate by hand. The codemods for 0014 and 0015 ship in 0.94.0, and the others ship in 0.95.0.
