The JSDoc in the built types now matches the docs pages for about 50 components, including `Button`, `IconButton`, `Field`, `Sidebar`, `Command`, `Breadcrumb`, `AlertCenter`, `Sandbar`, `DataTable`, `List`, and the charts. Em-dash asides are now parentheticals, colons, or separate sentences. The editor hover text and `llms.txt` read the same as the docs.
