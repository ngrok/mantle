Add a `2xs` size to `IconButton`: a 20px box with a 16px icon. Use it for a copy button or another action inside a `DescriptionList` row, so the row keeps the same height as a row without an action. `2xs` is for `IconButton` only; `Button` and `SplitButton` keep the shared `xs` to `xl` scale.
